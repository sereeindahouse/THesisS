# Codex-д өгөх даалгавар — сургуулийн хүснэгтийг ресепшний системд холбох (2026.11.06)

**Асуудал:** `reception_tables.py` ресепшний асуултад хүснэгтээс хариулдаг. Энэ код бэлэн, 36 тест PASS, `config/reception-tables.json`-оор унтраалттай. Гэхдээ энэ код зөвхөн `rooms`, `staff`, `classes`, `timetable` гэсэн 4 хуудастай, англи баганатай XLSX уншдаг. Сургуульд өгсөн загвар бол `data/school-request/ШМТК_сургуульд_өгөх_хүснэгт.xlsx`. Үүнийг `tools/build_school_data_list.py` үүсгэдэг. Тэр нь Монгол нэртэй 7 хуудастай: тайлбар мөр, саарал жишээ мөр, «Алба, үйлчилгээ» ба «Улирлын огноо» хүснэгттэй. Иймээс сургууль бөглөж өгөхөд систем шууд уншиж чадахгүй.

**Хийх:**
1. `tools/import_school_tables.py` бичих. Сургуулийн загварыг уншаад `reception_tables.SCHEMA`-д нийцсэн 4 CSV-г `runtime/school-tables/<огноо>/` руу гаргана (runtime нь git-д ордоггүй). Дүрэм:
   - 1-р мөр тайлбар, 2-р мөр Монгол толгой, 3-р мөр жишээ — алгасна.
   - Монгол баганыг англи талбарт буулгана, буулгалтын хүснэгтийг кодод нэг газар бичнэ.
   - Хоосон мөрийг алгасна.
   - Алдаатай мөр олдвол аль хуудас, аль мөр гэдгийг хэлээд бүх импортыг зогсооно.
2. «Алба, үйлчилгээ»-г (номын сан, сургалтын алба г.м.) одоогийн schema-д хэрхэн оруулах вэ? `rooms`-ийг өргөтгөх үү, шинэ `offices` хүснэгт нэмэх үү? Аль нэгийг сонгож, яагаад гэдгээ бич. «Улирлын огноо»-г `timetable_complete` ба амралттай холбо.
3. Ресепшний 12 асуулт (`build_school_data_list.QUESTIONS`) бүрд нэг тест бичнэ. Хуурамч жишээ өгөгдлийг `is_fake=True` гэж тэмдэглэнэ. «Бат багш одоо хичээлтэй юу?» асуултын хариу заавал «хуваариар бол» гэж эхэлнэ. Байршлыг батлахгүй.
4. Сургууль загвараа ашиглалгүй өөрийн Excel хуваарийг өгч магадгүй. Үүнд зориулж импортыг тусад нь нэмэхгүй. Зөвхөн «загварт хуулж оруулах» заавар бичнэ.

**Хийхгүй:** `config/reception-tables.json`-ийг асаахгүй. LLM/Gemini/сүлжээ, шинэ хамаарал нэмэхгүй. `rule_selector.py`, эхийн хамгаалалт, RAG хайлтыг өөрчлөхгүй. Бодит хүний нэр, утас ашиглахгүй. main-д шууд commit хийхгүй.

**Хүлээлгэж өгөх:** `codex/reception-import-20261106` салаа. Мөн богино тайлан: юу хийсэн, тестийн команд ба дүн, сонгосон schema-ийн шийдвэр, үлдсэн асуудал. Claude шалгаж main-д нийлүүлнэ (11/04-ний журмаар).
