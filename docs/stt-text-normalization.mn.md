# STT текстийн хайлтын хуулбар — туршилтын боломж

`config/stt-text-normalization.json` дахь `enabled` нь анхнаасаа `false`.
Gemini-ийн model, API хүсэлт, танигдсан эх текст, WER/CER оноог өөрчлөхгүй.

Идэвхжүүлсэн үед `Normalizer.from_config(root).normalize(text)` нь
`original_text`, `normalized_search_text`, `changed`, `replacements` буцаана.
`replacements` бүр эх текстийн `start`/`end`, өмнөх ба дараах утга, `kind`-тай.
Хэрэглэгчийн баталсан эхийг орлуулахгүй; хайлтын хуулбарыг тусад нь харуулж болно.

Чатын `/api/route` замд серверээр баталгаажсан `raw_stt` / `edited_stt`
гаралтай үед л энэ алхмыг хэрэглэнэ. Гараар бичсэн асуултад хэрэглэхгүй.
Хариуны `query`, дахин дуудах болон TTS-ийн холбоос анхны асуулттай хэвээр;
хайлтын хувилбарыг `search_normalization` metadata-д тусад нь хадгална.
Хуулбар өөрчлөгдвөл чатанд эх танилтын тайлбарын хамт харагдана.
Үүнийг хүний засвар, raw STT-ийн чанарын өсөлт гэж тооцохгүй.

Зохиомол жишээ: `Зохиомолын лаборатоори хоёр мянга хорин зургаан онд БИШ.`
→ `Зохиомолын лаборатори 2026 онд БИШ.`. Энэ нь бодит сургуулийн мэдээлэл биш.

Тоо: 0–999999-ийн бүтэн Монгол бүхэл тооны хэллэгийг цифр болгоно.
`tools/compare_stt_vocabulary.py`-ийн `spoken_year` дахь 2000–2099 оны
тоо/хувилбарын дүрмийг цэвэр текстийн grammar-д ашигласан; evaluation runner
импортлохгүй. Дан `нэг`, `хоёр` зэрэг үгэнд хэмжих нэр (`хүн`, `он`, `багш`,
`төгрөг` гэх мэт) залгасан үед л хувиргана. Дараалсан `нэг хоёр`, цифртэй
холилдсон дутуу хэллэг, утас/код/аравтын бутархай, URL, имэйл, backtick доторх
текстийг тааж тайлахгүй. Цифрүүдийн эх хэлбэр хэвээр (`002026` код мөн адил).

Нэр томьёо: зөвхөн `config/stt-vocabulary.json`-ийн `terms` жагсаалтаас авна.
Өөрчлөгдөх нэг үг дор хаяж 8 тэмдэгттэй, бүхэл хэллэгт ганц edit,
ижил төстэй байдал ≥0.90, ганц боломжит нэр томьёо үед л солино.
Зөв бичсэн үг, товчлол/богино нэр, олон боломжит ойролцоо үг, цэгтэй эхний
үсэг, хэт өөр бичлэгийг орхино. Үгүйсгэл, бусад үг, цэг тэмдэг, гаднах зайг хадгална.

Энэ бол зориуд хязгаарласан rule-based туршилт. Бүх Монгол тооны хувилбар,
дугаарын дараалал, нөхцөлтэй үг, ordinal/аравтын бутархайг дэмжихгүй.
Шинэ model-ийн чанарын ахиц хэмжээгүй; зөвхөн зохиомол текстийн unit test-тай.
Тохиргоо буруу/дутуу, vocabulary буруу бол боломж унтраалттай буцна.
API түлхүүр, runtime, аудио, DB уншихгүй; зөвхөн тогтсон хоёр config файл уншина.
