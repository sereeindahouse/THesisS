# W09 — ресепшний дөрвөн хүснэгтийн бэлтгэл

Энэ модуль нь сургууль өгөгдлөө хянаж өгсний дараа өрөөний давхар болон
багшийн **хуваарьт төлөвийг** хүснэгтээс харахад зориулагдсан. Анхнаасаа
`config/reception-tables.json`-ийн `enabled: false`; бодит мэдээлэл одоо ороогүй.
Үндсэн RAG эх сонгох дүрмийг солихгүй.

| Хүснэгт / XLSX sheet | Заавал байх баганууд |
|---|---|
| rooms | floor, name |
| staff | name, department, room, office_hours |
| classes | group, room |
| timetable | day, time, group, room, teacher |

`staff.name` нь багшийг нэг утгаар таних нэмэлт түлхүүр. `rooms.name`,
`staff.name`, `classes.group` давхардаж болохгүй. Хоосон талбар, танихгүй
өрөө/бүлэг/багшийн холбоос, хуваарийн давхцлыг loader бүхлээр нь татгалзана.
`office_hours` нь хүн унших текст; багш тэр цагт өрөөндөө байна гэсэн нотолгоо биш.

CSV бол нэг хавтсанд `rooms.csv`, `staff.csv`, `classes.csv`, `timetable.csv`
дөрвүүл байна. UTF-8 (BOM байж болно), эхний мөр нь баганын нэр. XLSX бол яг
эдгээр нэртэй дөрвөн sheet, эхний мөр нь ижил баганууд; нэмэлт сан шаардлагагүй.
Formula, гадаад холбоос, том/эвдэрхий ZIP/XML-ийг татгалзана. Excel-ийн time/date
serial тооны оронд цагийг **текстээр** `09:00-10:00` гэж бичнэ.

`day` нь `mon..sun` эсвэл Даваа..Ням. `time` нь `HH:MM-HH:MM`; нэг өдөрт
эхлэх цаг < дуусах цаг, хоорондоо залгаа хичээл боломжтой. Нэг багш/бүлэг/өрөө
хоёр давхцсан хичээлтэй байж болохгүй. Цаг эхлэхдээ багтана, дуусахдаа багтахгүй.

Сургууль өгөгдлийг хянасны дараа project доторх `data/reception/` дахь CSV
хавтас эсвэл XLSX файлын харьцангуй замыг `source`-д бичээд `reviewed: true`,
`enabled: true` болгоно. `timetable_complete: true` нь долоо хоногийн бүх
хичээлийг бүрэн оруулсан гэсэн **операторын баталгаа**. Үүнгүй бол мөргүй
цагийг «чөлөөтэй» гэж зарлахгүй. Хуваарь хичээлгүй гэдэг нь хүн уулзахад бэлэн
эсвэл хаана байгааг батлахгүй; өөрчлөгдсөн/цуцалсан хичээлийг бүртгэл өөрөө мэдэхгүй.

Зөвшөөрөх асуулт нь хаалттай: `FAKE-201 өрөө хаана вэ?`,
`Зохиомол Наран багш хаана вэ даваа 09:30?`, `where is room FAKE-201?`.
Нэрийг хүснэгттэй бүтнээр тулгана; ойролцоо хүнийг таахгүй. Багшийн асуултад
цаг өгөөгүй бол серверийн дуудаж буй тал `now=datetime(...)` өгөх эсвэл
өдөр/цаг тодруулах шаардлагатай. Тохиромжгүй олон сэдэвт асуултыг үндсэн router-т үлдээнэ.

Багшид өгөх мэдээлэл зөвхөн «Хуваарийн дагуу (даваа 09:30): хичээлтэй /
хичээлгүй (чөлөөтэй). Бодит байршлыг батлахгүй.» Өдөр, цаг нь хариултын
текстэд үлдэнэ; дараа нь унших/сонсоход өнөөгийн төлөв мэт ойлгуулахгүй.
Багшийн өрөө, анги, хичээл явагдах
өрөөг энэ хариултад гаргахгүй. Room lookup нь харин тухайн өрөөний давхрыг гаргана.

`tests/fixtures/reception_fake/` доторх CSV/XLSX бүгд **FAKE / зохиомол**.
Сургуулийн бодит өгөгдөл биш. Зөвхөн тестэд `is_fake: true` гэж заахад fixture
замыг config хүлээн авна, бүх хариултад FAKE гэсэн тэмдэг гарна.

Python API:

```python
from reception_tables import ReceptionAnswerPath, load_tables

tables = load_tables('tests/fixtures/reception_fake', is_fake=True)
path = ReceptionAnswerPath(tables, enabled=True)
result = path.answer('FAKE-201 өрөө хаана вэ?')
# result: query, answer, reason_code, reception metadata
# Үндсэн сервер: ReceptionAnswerPath.from_config(project_root)
```

`None` нь disabled/энэ замын асуулт биш. Танигдсан ч эх/цаг дутуу үед `answer=None`
ба шалтгааны код өгнө. Loader зөвхөн уншина; хүснэгтүүд санах ойд immutable tuple/dataclass.
DB, сүлжээ, модель, аудио ашиглахгүй.
