# W09 — ресепшний дөрвөн хүснэгтийн бэлтгэл

**2026.11.06 — Монгол сургуулийн загвараас импортлох.**
`tools/import_school_tables.py` нь сургуулийн долоон хуудастай шинэ загварыг
дөрвөн CSV болон `import-metadata.json` болгон хувиргана. Сүлжээ, LLM,
Gemini, нэмэлт Python сан хэрэглэхгүй; тохиргоог асаахгүй.

```powershell
.venv/Scripts/python.exe tools/import_school_tables.py "бөглөсөн-загвар.xlsx" --date 2026-11-06
```

Гаралт: `runtime/school-tables/2026-11-06/`. Өмнө үүссэн хавтсыг дарахгүй.
Буруу мөр байвал хуудас, Excel мөрийн дугаарыг заагаад бүх импортыг зогсооно;
хүний нэр, утас, нүдний утгыг терминалд хэвлэхгүй. Эх файл өөрчлөгдөхгүй.
CSV-үүдийг эхлээд түр хавтсанд production loader-аар шалгаж, амжилттай бол
хавтсыг бүхлээр нь нийтэлнэ. Бодит бөглөсөн файл болон гаралтыг Git-д оруулахгүй.

Таван өгөгдлийн хуудсанд 1-р мөр тайлбар, 2-р мөр баганын нэр, 3-р мөр саарал
жишээ; зөвхөн **4-р мөрөөс** өгөгдөл оруулна. Жишээг өөрчилж бөглөхгүй.
Хоосон мөр алгасна. Толгойг өөрчлөхгүй, баганыг байрлалаар нь сольж болно.
Багана нэмэхгүй. Өрөө/бүлэг/багшийн холбоосууд бүтэн нэрээр таарна.
Ижил багш, бүлэг, өрөөний давхардсан цагийг татгалзана. Цагийг
`09:00–10:30` эсвэл `09:00-10:30` текстээр бичнэ.

`Улирлын огноо` хуудас өөр бүтэцтэй: **A1–A3 шошго хэвээр, B1–B3 утга**.
B1 эхлэл, B2 төгсгөл нь `YYYY-MM-DD` текст. B3 амралтын ISO огноонуудыг
таслал/цэгтэй таслалаар салгана; дараалсан өдрийг `2030-02-01..2030-02-07`
гэж өгч болно (зохиомол жишээ). Амралтгүйг хүн шалгасан бол `байхгүй`
эсвэл `—` гэж бичнэ; хоосон гэдэг нь амралтгүй гэсэн баталгаа биш.
Excel-ийн дотоод date/time serial тоо, томьёо, гадаад холбоосыг хүлээж авахгүй.
`Ресепшний асуулт` хуудас нь заавар; түүний өгүүлбэрийг fact болгон импортлохгүй.

`--timetable-complete`-ийг хүн бүх бүлгийн долоо хоногийн хуваарь, улирлын
эхлэл/төгсгөл, бүх амралтыг хянасан үед л өгнө. Огноо ба амралтын баталгаа
дутуу бол энэ сонголттой импорт татгалзана. Анхны импортын утга `false`.
Улирлаас гадуур, амралтын өдөр, огноо тодорхойгүй үед «хичээлтэй/чөлөөтэй»
гэж дүгнэхгүй. Хуваарьт төлөв нь хүний бодит байршил, ирцийг батлахгүй.

**Schema-ийн шийдвэр:** `offices` гэсэн тав дахь хүснэгт нэмээгүй.
`rooms`-д `purpose`, `department`, `services` нэмэлт талбар оруулсан.
`services` нь `{name, office_hours, contact}` объектуудын JSON жагсаалт;
нэг өрөөнд олон алба байж болно. Албаны өрөө тусдаа өрөөний хуудсанд байхгүй
бол албаны мөрийн батлагдсан өрөө/давхраас нэмж болно; зөрсөн давхар татгалзана.
Нэг албаны нэр давхардахгүй. Контакт дутууг `—` эсвэл хоосон гэж өгч болно;
хоосон контактаас дугаар зохиохгүй. `staff.role`, `classes.course/department/teacher`,
`timetable.subject` нэмэлт талбарууд нь шинэ загварын утгыг хадгална.
Хуучин дөрвөн CSV/XLSX-ийн заавал багана хэвээр тул хуучин fixture ажиллана.

**Сургууль өөрийн Excel-ийг өгвөл:** шинэ формат таадаг импорт нэмээгүй.
Хүн эх хувийг хадгалаад сургуулийн загварын 4-р мөрөөс холбогдох утгуудыг
**Paste values / зөвхөн утгаар** хуулна. Өрөө, багш, бүлгийн бүтэн түлхүүр,
гараг/цаг, улирлын огноо ба амралтыг нэг нэгээр тулгана. Хуваарийн нүдний
өнгө, нийлүүлсэн гарчиг, томьёог өгөгдөл гэж тайлбарлахгүй. Дараа нь дээрх
импорт, хүний эхтэй тулгалтыг хийнэ.

**Хянасан өгөгдлийг системд оруулах:** runtime замыг config loader зориуд
хориглодог хэвээр. Эхтэй нь хүн тулгаж зөвшөөрсний дараа дөрвөн CSV ба metadata-г
хамтад нь шинэ `data/reception/<хувилбар>/` хавтаст хуулж, тусдаа шийдвэрээр
source/reviewed/enabled тохируулна. Энэ ажлаар ийм хуулалт, тохируулга хийгээгүй.
Хэсэгчилсэн CSV эсвэл metadata-г орхиж зөөхгүй. `load_tables(runtime_path)` нь
офлайн шалгалтад боломжтой; үндсэн серверт автоматаар холбогдохгүй.

Шинэ 12 асуултын «Ангийн багш хэн бэ?» нь бүлэг нэрлээгүй тул бүлгийг
тодруулна. «Бат багш одоо хичээлтэй юу?» гэсэн зохиомол тестийн хариу
«Хуваариар бол» гэж эхэлж, байршлыг батлахгүй. Бүтэн нэрийг богино нэрээр
ойролцоолон таахгүй. Тэнхимийн асуултад бүртгэлд хамаарах өрөөг харуулж,
тэдгээрийг ганц төв байр гэж батлахгүй.

Одоогийн серверийн `reception_clock` анхны утга `None` хэвээр. «Одоо/өнөөдөр»
асуултад дараа нь серверийн дуудаж буй тал сургуулийн орон нутгийн зөв
`datetime`-ийг ил тод нийлүүлэх шаардлагатай. Энэ ажлаар RAG/runtime холболтыг
өөрчлөөгүй; цаггүй үед цаг/огноо тодруулна, машины цагийг далдуур ашиглахгүй.

---

Энэ модуль нь сургууль өгөгдлөө хянаж өгсний дараа өрөөний давхар болон
багшийн **хуваарьт төлөвийг** хүснэгтээс харахад зориулагдсан. Анхнаасаа
`config/reception-tables.json`-ийн `enabled: false`; бодит мэдээлэл одоо ороогүй.
Үндсэн RAG эх сонгох дүрмийг солихгүй.

| Хүснэгт / XLSX sheet | Заавал байх баганууд |
|---|---|
| rooms | floor, name |
| staff | name, department, room, office_hours |
| classes | group, room |
| timetable | day, time, group, room, teacher |

`staff.name` нь багшийг нэг утгаар таних нэмэлт түлхүүр. `rooms.name`,
`staff.name`, `classes.group` давхардаж болохгүй. Хоосон талбар, танихгүй
өрөө/бүлэг/багшийн холбоос, хуваарийн давхцлыг loader бүхлээр нь татгалзана.
`office_hours` нь хүн унших текст; багш тэр цагт өрөөндөө байна гэсэн нотолгоо биш.

CSV бол нэг хавтсанд `rooms.csv`, `staff.csv`, `classes.csv`, `timetable.csv`
дөрвүүл байна. UTF-8 (BOM байж болно), эхний мөр нь баганын нэр. XLSX бол яг
эдгээр нэртэй дөрвөн sheet, эхний мөр нь ижил баганууд; нэмэлт сан шаардлагагүй.
Formula, гадаад холбоос, том/эвдэрхий ZIP/XML-ийг татгалзана. Excel-ийн time/date
serial тооны оронд цагийг **текстээр** `09:00-10:00` гэж бичнэ.

`day` нь `mon..sun` эсвэл Даваа..Ням. `time` нь `HH:MM-HH:MM`; нэг өдөрт
эхлэх цаг < дуусах цаг, хоорондоо залгаа хичээл боломжтой. Нэг багш/бүлэг/өрөө
хоёр давхцсан хичээлтэй байж болохгүй. Цаг эхлэхдээ багтана, дуусахдаа багтахгүй.

Сургууль өгөгдлийг хянасны дараа project доторх `data/reception/` дахь CSV
хавтас эсвэл XLSX файлын харьцангуй замыг `source`-д бичээд `reviewed: true`,
`enabled: true` болгоно. `timetable_complete: true` нь долоо хоногийн бүх
хичээлийг бүрэн оруулсан гэсэн **операторын баталгаа**. Үүнгүй бол мөргүй
цагийг «чөлөөтэй» гэж зарлахгүй. Хуваарь хичээлгүй гэдэг нь хүн уулзахад бэлэн
эсвэл хаана байгааг батлахгүй; өөрчлөгдсөн/цуцалсан хичээлийг бүртгэл өөрөө мэдэхгүй.

Зөвшөөрөх асуулт нь хаалттай: `FAKE-201 өрөө хаана вэ?`,
`Зохиомол Наран багш хаана вэ даваа 09:30?`, `where is room FAKE-201?`.
Нэрийг хүснэгттэй бүтнээр тулгана; ойролцоо хүнийг таахгүй. Багшийн асуултад
цаг өгөөгүй бол серверийн дуудаж буй тал `now=datetime(...)` өгөх эсвэл
өдөр/цаг тодруулах шаардлагатай. Тохиромжгүй олон сэдэвт асуултыг үндсэн router-т үлдээнэ.

Багшид өгөх мэдээлэл зөвхөн «Хуваарийн дагуу (даваа 09:30): хичээлтэй /
хичээлгүй (чөлөөтэй). Бодит байршлыг батлахгүй.» Өдөр, цаг нь хариултын
текстэд үлдэнэ; дараа нь унших/сонсоход өнөөгийн төлөв мэт ойлгуулахгүй.
Багшийн өрөө, анги, хичээл явагдах
өрөөг энэ хариултад гаргахгүй. Room lookup нь харин тухайн өрөөний давхрыг гаргана.

`tests/fixtures/reception_fake/` доторх CSV/XLSX бүгд **FAKE / зохиомол**.
Сургуулийн бодит өгөгдөл биш. Зөвхөн тестэд `is_fake: true` гэж заахад fixture
замыг config хүлээн авна, бүх хариултад FAKE гэсэн тэмдэг гарна.

Python API:

```python
from reception_tables import ReceptionAnswerPath, load_tables

tables = load_tables('tests/fixtures/reception_fake', is_fake=True)
path = ReceptionAnswerPath(tables, enabled=True)
result = path.answer('FAKE-201 өрөө хаана вэ?')
# result: query, answer, reason_code, reception metadata
# Үндсэн сервер: ReceptionAnswerPath.from_config(project_root)
```

`None` нь disabled/энэ замын асуулт биш. Танигдсан ч эх/цаг дутуу үед `answer=None`
ба шалтгааны код өгнө. Loader зөвхөн уншина; хүснэгтүүд санах ойд immutable tuple/dataclass.
DB, сүлжээ, модель, аудио ашиглахгүй.
