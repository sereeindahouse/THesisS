Энэ багц нь I-ийн ресепшний W09 бэлтгэл, II-ийн STT текстийг хайлтад бэлтгэх
алхам, III-ийн тест ажиллуулах орчны ажил. Гурван үндсэн хэсэг дууссан гэсэн үг биш.

Салбар: `feat/reception-offline-normalization-20261104`.

Эхэнд хэрэглэгчийн хүссэн GitHub шалгалтыг нэг удаа хийсэн; түүнээс хойш гаднын
сүлжээ/API дуудаагүй. Main-д merge, remote push хийгээгүй.

## Хийсэн ажил

| Ажил | Гарсан зүйл | Анхны төлөв |
|---|---|---|
| Ресепшний дөрвөн хүснэгт | CSV/XLSX loader, холбоос/давхцал шалгалт, FAKE fixture, өрөө/багшийн хуваарийн хариу | `config/reception-tables.json`: OFF, reviewed=false |
| STT-ийн хайлтын текст | Монгол бүхэл тоо/он → цифр; vocabulary-ийн ганц утгатай, маш ойр алдаа → зөв нэр | `config/stt-text-normalization.json`: OFF |
| Бүтэн суит | `tests` багц, үндсэн хавтаснаас discovery, тусгаарласан runner ба JSON тайлан | Хуучин тестийн assertion өөрчлөөгүй |

Багшийн хариу зөвхөн **тухайн өдөр/цагийн хуваариар хичээлтэй эсвэл хичээлгүй**
гэж хэлнэ. Бодит байршил, өрөөндөө байгаа эсэхийг батлахгүй. Хуваарь бүрэн
гэдгийг оператор батлаагүй бол мөргүй цагийг чөлөөтэй гэж тооцохгүй.
Бодит сургуулийн хүснэгт оруулаагүй.

STT-ийн анхны текст, хариуны query болон TTS/дахин дуудах холбоос хадгалагдана.
Сервер баталсан STT гаралтай асуултын хайлтын хуулбарыг л хувиргана;
гараар бичсэн асуултыг хэвээр үлдээнэ. Өөрчлөлтийн span, эх/дараах утга тусдаа
metadata болон UI тайлбартай. `gemini-3.5-transcribe`, API хүсэлт,
`config/stt-vocabulary.json`, одоогийн эх сонгох дүрмийн тохиргоог өөрчлөөгүй.

## Бодит шалгалт

Одоо байгаа `.venv-modeltools` Python 3.11 орчныг ашигласан; dependency,
модель шинээр татаагүй. Үндсэн команд:

```powershell
python -m unittest discover
```

Энэ ажилд бодит өгөгдөлд хүрэхгүй байхын тулд дараах wrapper-аар ижил
`unittest discover -p test*.py`-г цэвэр түр хуулбарт ажиллуулсан:


## Өгөгдлийн зааг ба дараагийн алхам

Бүтэн тест эх төслийн runtime, модель, аудио, DB, нууц, бодит transcript-ийг
уншаагүй/хуулбарлаагүй. Нийтийн сургуулийн дөрвөн JSON, код/тохиргоо болон FAKE
fixture-ийг л хуулсан. Хуучин тестүүд өөрсдөө түр орчиндоо зохиомол DB/аудио
үүсгэсэн; зөвхөн loopback fake сервер зөвшөөрсөн, гадаад Python socket хориглосон.
Хэрэглэгчийн өмнөх untracked PPT-г хөндөөгүй.

Хоёр боломж OFF хэвээр. Бодит ярианы WER/CER, хүний үнэлгээ эсвэл хариултын
чанарын шинэ өсөлт хэмжээгүй. Хайлтын текстийн дүрэм бүх тоо/хувиллыг хамрахгүй;
маш ойр бичлэг ч утгын баталгаа биш. Хүснэгт идэвхжүүлэхээс өмнө сургуулийн
эх, нэр, өдөр/цаг, хуваарийн бүрэн байдлыг хянана.

Дараагийн инженерийн нэг ажил: дээрх хоёр хуучин contract-ийг тусдаа багцад
огнооны ил тод clock injection, provider-ийн ил тод fixture сонголтоор
тогтвортой болгох; expiry/token хамгаалалтыг хэвээр хадгалах.
