# Дипломын бодит үр дүн — 2026.10.10

Одоо **бичгэн асуулт → SQLite → BM25 FAQ хайлт → сонгосон FAQ ба эхийг үзэх** урсгал браузераас ажилладаг. `python demo_server.py` ажиллуулаад **http://127.0.0.1:8765** нээнэ. [Demo-г ашиглах заавар](SQLITE-SEARCH.mn.md).

Энэ нь хөгжүүлэлтийн төлөв. Эцсийн судалгааны үр дүн, сургуулийн баталгаа эсвэл бүх хэрэглэгчийн чанарын дүгнэлт биш.

| Хэсэг | Бодит дүн | Үлдсэн асуудал |
|---|---|---|
| STT | Ижил 13 батлагдсан reference дээр Cafet small WER 36.0%, CER 16.9%; дөрвөн Монгол хувилбар харьцуулсан | Нэг хүний хөгжүүлэлтийн бичлэг; он/нэр/дугаарын алдаа; зургаан бүтэн зөв текст үлдсэн |
| TTS | Хоёр шинэ хувилбарыг хэрэглэгч өмнөхөөс дээр гэж үнэлсэн | Нэр/тоо/огнооны нарийвчилсан сонсгол, эцсийн хоолой/үйлчилгээ |
| Агуулга | Зургаан эх, 10 fact, таван FAQ-ийн draft | Албаны баталгаа, хүчинтэй хугацаа, элсэлтийн хуудасны зөрчил |
| Хайлтын өмнөх хэмжилт | Таван FAQ, 15 proposed асуулт дээр top1 BM25 10/15, E5 14/15 | Хүний баталсан query–FAQ холбоо, том corpus; энэ дүн системийн зөв хариултын хувь биш |
| SQLite хайлт | Одоо асуултаар BM25 эрэмбэ, FAQ ID, хамрах хүрээ, эх/хувилбар гаргана; зөвхөн унших snapshot | Fuzzy candidate-аас асуултад зөв хариулах боломжийг батлах ажиллагаа |
| Браузерын demo | Амьд SQLite хайлт, илэрхий FAQ preview, баталгааны хамгаалалт, q01–q03 тоглуулагч | Микрофон/STT/TTS холболт, бүтэн A/B/C/D/E router, deployment |
| Судалгаа | 20 гол + 6 нэмэлт эх; наймын сонгосон арга нягталсан | Бүтэн өгүүллийн гүн уншлага ба суралцагчийн тэмдэглэл |

WER 36.0% нь таних accuracy биш. Энэ багцын 186 үгт 67 үг солих/орхих/нэмэх засвар шаардсан гэсэн харьцаа. 1−WER-ийг утгын зөв ойлголтын хувь гэж нэрлэхгүй. Өөр reference cohort-ийн оноог сайжрал гэж харьцуулахгүй.

E5-ийн 14/15 нь draft FAQ-г олох жижиг туршилт. Хариулт нь corpus-д байхгүй таван асуулт ч 0.789–0.832 төстэй оноо авсан. Хайлтын оноог зөв хариултын магадлал гэж хэрэглэхгүй. [Хайлтын дэлгэрэнгүй](RETRIEVAL-RESULTS.mn.md).

Шинэ SQLite хайлт өмнөх BM25 scorer-ийг ашигладаг. Байгаа DB-г уншаад нэг багцын хувилбарыг тогтооно; эх/хувилбар буцааж олдоно. Хугацаа дууссан, хүчингүй эсвэл баталгаагүй агуулгыг approved хариулт болгохгүй. Fuzzy matching-ээс автомат answer үүсэхгүй. Хүчинтэй хугацаа дутуу эсвэл хариулт хэсэгчилсэн үед approved preview хаагдана; explicit draft preview хамрах хүрээ, хязгаарлалттай харагдана.

Бодит таван FAQ дээр холбоо барих exact alias ердийн горимд хаагдаж, `--allow-draft` үед хөгжүүлэлтийн preview гарсан. Өөрөөр хэлсэн утасны асуулт candidate олсон; гадаад паспортын асуулт lexical candidate олоогүй; 2027 оны төлбөрийн асуултад төлбөр зохиогоогүй. Эдгээр шалгалтаар DB-ийн hash өөрчлөгдөөгүй. Шинэ training, STT/E5 inference хэмжилт, LLM дуудалт хийгээгүй.

Хэрэглэгчийн шинэ зөвшөөрлөөр **q01–q03 дууны гурван жишээ** болон өмнөх батлагдсан текст/хадгалсан STT гаралтыг demo-д оруулсан. Бусад хувийн дуу, transcript, чат нийтлэлд ороогүй. Дуу тоглуулах нь шинэ inference биш. Туршсан Cafet STT ба E5 жин [GitHub Release](https://github.com/sereeindahouse/THesisS/releases/tag/models-20261010)-д нийтлэгдсэн; серверийн хэмжээ/SHA256 нь локал архивтай таарсан. [Модель суулгах зааварт](MODEL-SETUP.mn.md) байрлал, лиценз, manifest/hash-ийн шалгалт бий.

Хоёр дахь долоо хоногийн хүний зөв текст/TTS/асуулт–эхийн аудит бүрэн биш. Тэдгээртэй зэрэгцүүлэн схем/embedding/SQLite болон бичгэн demo-г эрт хэрэгжүүлсэн. Эцсийн roadmap-ийн огноо, шалгуурыг өөрчлөөгүй. Бүтэн voice/router/C-RAG болон эцсийн чанарын хүлээн авалт дуусаагүй.
