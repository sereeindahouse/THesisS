# Дипломын бодит үр дүн — 2026.10.10

Энэ нь хөгжүүлэлтийн төлөв. Эцсийн судалгааны үр дүн, сургуулийн баталгаа эсвэл бүх хэрэглэгчийн чанарын дүгнэлт биш.

| Хэсэг | Бодит дүн | Үлдсэн асуудал |
|---|---|---|
| STT | Ижил 13 батлагдсан reference дээр Cafet small WER 36.0%, CER 16.9%; дөрвөн Монгол хувилбар харьцуулсан | Нэг хүний хөгжүүлэлтийн бичлэг; он/нэр/дугаарын алдаа; зургаан бүтэн зөв текст үлдсэн |
| TTS | Хоёр шинэ хувилбарыг хэрэглэгч өмнөхөөс дээр гэж үнэлсэн | Нэр/тоо/огнооны нарийвчилсан сонсгол, эцсийн хоолой/үйлчилгээ |
| Агуулга | Зургаан эх, 10 fact, таван FAQ-ийн draft | Албаны баталгаа, хүчинтэй хугацаа, элсэлтийн хуудасны зөрчил |
| Хайлт | Таван FAQ, 15 proposed асуулт дээр top1 BM25 10/15, E5 14/15 | Хүний баталсан query–FAQ холбоо, том corpus, эхгүй асуултад хариулахгүй ажиллагаа |
| SQLite | Давхардахгүй импорт, багцын түүх, эх/хувилбар, fact/FAQ preview | Автомат асуултын router, alias ба он/нэрийн бодлого |
| Судалгаа | 20 гол + 6 нэмэлт эх; наймын сонгосон арга нягталсан | Бүтэн өгүүллийн гүн уншлага ба суралцагчийн тэмдэглэл |

WER 36.0% нь таних accuracy биш. Энэ багцын 186 үгт 67 үг солих/орхих/нэмэх засвар шаардсан гэсэн харьцаа. 1−WER-ийг утгын зөв ойлголтын хувь гэж нэрлэхгүй. Өөр reference cohort-ийн оноог сайжрал гэж харьцуулахгүй.

E5-ийн 14/15 нь draft FAQ-г олох жижиг туршилт; систем зөв хариулсан хувь биш. Хариулт нь corpus-д байхгүй таван асуулт ч 0.789–0.832 төстэй оноо авсан. Хайлтын оноог зөв хариултын магадлал гэж хэрэглэхгүй. [Хайлтын дэлгэрэнгүй](RETRIEVAL-RESULTS.mn.md).

SQLite нь схемээс бодит хадгалалт руу ахисан суурь. Ижил draft багцыг импортлох, дахин импортлоход шинэ мөр нэмэгдэхгүй байх, эхийн хувилбарыг хадгалах, баталгаагүй/хугацаа зөрсөн агуулгыг хариулт болгохгүй байх ажиллагааг шалгасан. Автомат router эсвэл генераци гэж тайлагнахгүй.

Хоёр дахь долоо хоногийн хүний зөв текст/TTS/асуулт–эхийн аудит бүрэн биш. Тэдгээртэй зэрэгцүүлэн гурав дахь долоо хоногийн схем/embedding болон дараагийн хадгалалтын суурийг эрт хийсэн. Эцсийн roadmap-ийн огноо, шалгуурыг өөрчлөөгүй.
