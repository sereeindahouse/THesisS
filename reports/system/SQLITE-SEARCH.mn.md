# Дууны урсгал, сонсгол ба SQLite хайлтын demo — 2026.10.10

**2026.10.10 шинэ төлөв:** ажиллах хувилбарын зорилт **2026.11.10**, дараа нь алдаа засах.
Demo шинэ chat загвартай; албан сайтын эхийг хэрэглэгчийн зөвшөөрлөөр normal горимд
ашиглана. Хуучин дутуу pilot сонсгол нь заавал биш архив, хөгжүүлэлтийн нөхцөл биш.
STT→текст засвар→эхтэй хариулт→TTS ажиллана. Optional локал LLM засварын холбоос
бэлэн; модель тохируулагдаагүй үед raw текст хэвээр, бодит LLM сайжрал хэмжээгүй.
192 кодын тест, шинэ интерфэйсийн браузерын 11 шалгалт тэнцсэн.
Normal FAQ жагсаалтаас эхтэй мэдээлэл сонгож үзнэ; эдгээр тест нь хариултын accuracy биш.


Одоо ажиллаж буй урсгал: **микрофон/аудио → локал STT → текст засвар → A/B/D/E чиглүүлэгч → эхтэй хариулт/тодруулга/татгалзал → TTS → тоглуулагч**. Бичгэн FAQ/веб эхийн хайлт мөн хэвээр. Энэ нь хязгаарласан хөгжүүлэлтийн demo; хамрах хүрээний өргөтгөл, C генераци, бодит төхөөрөмж/HTTPS ажиллагаа үлдсэн. Албан эхийг ашиглах хэрэглэгчийн шийдвэр normal горимд хэрэгжинэ.

## Demo-г нээх

Windows дээр төслийн үндсэн хавтасны **DEMO.cmd**-ийг хоёр дарж нээнэ.
Python эхлүүлэгч нь байгаа серверийг ашиглах эсвэл асааж, браузерт demo-г нээнэ.
Терминалын working directory өөр байсан ч төслийн өөрийн хавтсыг ашиглана.

Терминалаас нээх хувилбар:

```powershell
py -3.11 open_demo.py
```

Төслийн үндсэн хавтсаас Python 3.11 ашиглан:

```powershell
python demo_server.py
```

Браузертаа **http://127.0.0.1:8765** нээнэ. Терминалыг нээлттэй байлгана; `Ctrl+C` серверийг зогсооно. Энэ компьютерийн `runtime/content.db` өмнө импортлогдсон бол дахин импортлохгүй.

Шинэ clone-д DB байхгүй үед нэг удаа:

```powershell
py -3.11 import_content.py import data/content-draft-v1.json --allow-draft
py -3.11 demo_server.py
```

Бичгэн demo ба BM25-д Python standard library хангалттай. Дууны урсгалд
`requirements.txt`-ийн runtime сангууд ба локал Cafet жин хэрэгтэй;
[орчин/жин суулгах заавар](MODEL-SETUP.mn.md). Байгаа жинг дахин татахгүй;
сан/жин байхгүй clone-д бичгэн асуулт ажиллаж, дууны бэлэн биш төлөвийг харуулна.
DB үүсээгүй үед «SQLite бэлэн биш» гэж харуулна. Сервер зөвхөн localhost-д нээгдэж,
сургуулийн эхийн DB-г зөвхөн уншина. Сонсголын хэрэглэгчийн үйлдэл нь тусдаа хувийн
бүртгэлд бичнэ; сургуулийн агуулгыг батлах API биш.

## Дуугаар асуух

1. **«Ярьж асуух»** дарна. Браузерын микрофоны зөвшөөрлийг өгөөд
   «Холбоо барих утас хэд вэ?» гэж хэлж **«Бичлэг дуусгах»** дарна.
   Бичлэг 20 секундэд автоматаар зогсоно. Өмнөх WAV/WebM/Ogg/MP4 файл
   сонгоод **«Файлыг таних»** дарж болно; файл 30 секунд, 8 MiB хүртэл байна.
2. STT-ийн текст гармагц **«Таны асуулт»** хэсэгт үг, нэр, дугаарыг засна.
   Анхны гаралт, model load/inference/audio хугацаа нэмэлт хэсэгт байна.
   Засвар хийсний дараа **«Хариулт авах»** дарна.
3. Ердийн горимд ашиглахаар зөвшөөрсөн албан эхийн хариулт гарна. Он, хүрээ,
   эх дутуу бол тодруулга эсвэл шалтгаант татгалзал гарна. Хөгжүүлэгчийн draft
   сонголт зөвхөн нэмэлт техникийн хэсэгт бий; ердийн хариултад хэрэггүй.
4. Батаа эсвэл Есүйг сонгож **«Дуу үүсгэх»** дарна. Сервер асуултыг
   өмнө сонгосон агуулгын багцаар дахин чиглүүлж, эх/он/хамрах хүрээг шалгана.
   Унших текст онлайн Edge TTS-д илгээгдэнэ; хэрэглэгчийн аудио STT-д локал
   боловсруулагдана. Бэлэн дууны **▶** дарж сонсоно; автоматаар тоглуулахгүй.
5. **«Шинэ асуулт»** шинэ түр дуу/үр дүнг цэвэрлэж, микрофон ба
   тоглуулагчийг зогсооно. Эхний WAV болон хүний хадгалсан үнэлгээ хэвээр.

Микрофон эхлэхэд тоглож буй дууг зогсооно. Текст/горим өөрчлөгдөхөд хуучин
хариултын дууг хэрэглэхгүй. Reset эхэлсэн native STT тооцооллыг дундаас нь
таслахгүй; хожуу ирсэн хуучин үр дүнг дэлгэцэд ашиглахгүй. TTS тасарвал текстэн
хариулт хэвээр байна. Микрофоны зөвшөөрөл өгөөгүй бол файл/бичгэн асуулт ашиглана.

## Хуучин сонсголын хэрэгсэл — заавал биш архив

Энэ хэсгийг дахин хийх шаардлагагүй; хөгжүүлэлтийг зогсоох нөхцөл биш.
Хэрэгслийг архивын нэмэлт хэсэгт хадгалсан. Доорх нь өмнөх үнэлгээний аргачлал:
Энэ компьютерийн хувийн pilot/сонсголын файлууд байгаа үед л харагдана;
нийтийн шинэ clone-д эдгээр файл байхгүй гэсэн тайлбар гарна.

- STT-ийн q10/q13/q16/q17/q19/q20 дуугаа сонсоно. Draft текстийг бодитоор хэлсэн
  **бүх үгээр**, хураангуйгүй засна. Сонсож таарч байгааг батлах нүдийг сонгоод
  **«Зөв текстийг хадгалах»** дарна. q16 дээр хэлсэн утасны дугаарыг дуунаас
  нөхнө; моделийн таамгаар бүтээхгүй. q05 хасагдсан хэвээр байна.
- Гурван хяналттай TTS дууг сонсоод сонсогчийн нэр/код, ерөнхий чанар болон
  ойлгомжтой байдлын 1–5 оноо, нэр/ARC/Sakura/тоо/огнооны дуудлагын алдааг
  бичиж, өөрөө сонссоноо илэрхий тэмдэглэн хадгална. Алдаа сонсоогүй бол тэгж
  бичнэ. Энэ нь нэг сонсогчийн субъектив үнэлгээ; numeric MOS, эцсийн хоолойн
  сонголт эсвэл сургуулийн зөвшөөрөл болохгүй.

Хадгалалт нь аудионы hash-ийг шалгаж, backup/журналтай файл шинэчилнэ.
STT-ийн шинэ reference хадгалсны дараа локал скрипт байгаа бол **өмнө хадгалсан
model гаралтыг** дахин онооно; аудиог дахин танихгүй, жин сургахгүй. Оноо шинэчлэх
алдаа гарвал баталсан текст хадгалагдсан хэвээр бөгөөд алдааны төлөв харагдана.
Өөрчлөгдсөн reference cohort-ийн WER-ийг хуучин 13-ийн модель сайжрал гэж дүгнэхгүй.
Хувийн дуу/текст/үнэлгээ GitHub-д нийтлэгдэхгүй.

## Бичгэн хайлтаар юуг туршиж харах вэ?

1. **«Холбоо барих утас хэд вэ?»** гэж хайна. Бүртгэлтэй alias таарсан FAQ, эхийн холбоос, хувилбар харагдана. Албан эхийн зөвшөөрөгдсөн FAQ-г normal горимд сонгож үзнэ.
2. **«Эхтэй FAQ-г үзэх»** дарвал хадгалсан текст, хамрах хүрээ, эх ба татсан огноо гарна. Энэ нь сонгосон баримтын preview; асуултад зөв таарсан автомат хариулт гэсэн үг биш.
3. **«Сургуулийн утсыг хэлээч»** гэж өөрөөр асууна. Үгийн давхцал FAQ-г эрэмбэлж болно; сонгож үзсэн FAQ нь асуултад зөв хариулсан гэсэн баталгаа биш.
4. **«2027 оны сургалтын төлбөр хэд вэ?»** гэж асууна. Ойролцоо FAQ гарах боломжтой боловч систем төлбөр зохиож өгөхгүй. Одоогийн таван FAQ-д ийм батлагдсан мэдээлэл байхгүй.

Хайлт өөрөө answer буцаахгүй. Candidate сонгоход FAQ-г баримт үзэх хэлбэрээр харуулна. Албан эхийн бүрэн FAQ-д тусдаа school approval gate байхгүй. URL, эхийн dependency, мэдэгдэж буй хугацаа, хүчингүй/хэсэгчилсэн агуулгын хамгаалалт хэвээр. Хугацаа тодорхойгүй бол тодорхойгүй хэвээр харуулна; хүчинтэй оныг таамгаар зохиохгүй. Config байхгүй орчинд legacy strict горим; илэрхий draft preview мөн тусдаа.

## SQLite CLI ба Python API

```powershell
py -3.11 sqlite_retrieval.py "Холбоо барих утас хэд вэ?"
py -3.11 sqlite_retrieval.py "Холбоо барих утас хэд вэ?" --allow-draft --as-of 2026-10-10
```

CLI-ийн default нь BM25, legacy strict горим; demo серверийн хэрэглэгчийн зөвшөөрсөн эхийн бодлого нь `project_policy.py`-д тусдаа. Байгаа DB-г зөвхөн унших бөгөөд багцын snapshot-ийг тогтоож, FAQ ID, оноо, scope, баталгаа, эшлэлийн эх/хувилбарыг буцаана. `--package-id` хуучин багцыг сонгоно; `--top-k` эрэмбийн тоог тогтооно. `--output results/шинэ-нэр.json` зөвхөн шинэ файлд хадгална.

```python
from sqlite_retrieval import search_content

result = search_content("runtime/content.db", "Сургуулийн утсыг хэлээч",
                        backend="bm25", top_k=3, allow_draft=True)
```

CLI/API-д нэг canonical асуулт эсвэл хадгалсан alias яг таарсан үед л хязгаарласан exact preview боломжтой. Дүрэм нь тоо/он/нэрийг засаж таахгүй. Fuzzy matching нь үргэлж ranking төдий; өндөр онооноос хариулт сонгох босго нэмээгүй. Энэ preview нь бүх асуултын router хэрэгжсэн гэсэн үг биш.

`--backend e5` нь өмнө татсан, revision/hash шалгадаг локал жинг ашиглах тусдаа боломж. [Моделийн орчны заавар](MODEL-SETUP.mn.md) хэрэгтэй; demo хуудасны амьд хайлт BM25 хэвээр. Энэ нэгтгэл дээр E5 inference-ийг дахин хэмжээгүй.

## Өмнөх үр дүн ба одоогийн demo

- **STT:** 13 батлагдсан reference-ийн өмнөх Cafet small хэмжилт WER 36.0%, CER 16.9%. Энэ нь таних accuracy биш. Хуудсан дээр шинэ хэмжилт мэт тайлагнахгүй.
- **Хайлт:** өмнөх таван FAQ, 15 ассистентийн proposed асуултад BM25 top1 10/15, E5 top1 14/15. Query–FAQ холбоо хүний баталсан gold биш; системийн хариултын зөв хувь биш. [Хайлтын тайлан](RETRIEVAL-RESULTS.mn.md).
- **Агуулга:** зургаан эх, 10 fact, таван FAQ. Legacy draft metadata хэвээр; албан эхийг ашиглах хэрэглэгчийн шийдвэр normal горимд хүчинтэй. Эхгүй асуултын өндөр similarity нь дэмжсэн хариулт гэсэн үг биш.
- **Дуу:** хэрэглэгч нийтлэхийг зөвшөөрсөн q01–q03 WAV ба тэдгээрийн өмнөх transcript/STT үр дүнг доор сонсож/харна. Энэ нь хадгалсан жишээ; шинэ танилт, төгс чанарын баталгаа биш. [Жишээний manifest](../../demo/audio/samples.json).

Туршсан Cafet STT ба E5 жинг [GitHub Release](https://github.com/sereeindahouse/THesisS/releases/tag/models-20261010)-д тусдаа ZIP багцаар нийтэлсэн. GitHub-ийн серверийн хэмжээ/SHA256 нь локал архивтай таарсан. [Суулгах зааврын](MODEL-SETUP.mn.md) manifest/hash ба байрлалыг баримтална. Үндсэн Git-ийн source history-д том жин ороогүй; нийтийн pinned эхээс татах арга мөн хэвээр.

## Судалгааны үндэслэл

[BM25/E5 тэмдэглэл](../../papers/05-retrieval-method-notes.mn.md)-ийн дагуу lexical ба dense аргыг ижил query/corpus нөхцөлд ялгаж шалгана. Энэ demo BM25 scorer-ийг дахин ашигласан; өөрийн модель сургаагүй.

[ALCE, RAGAs, Human–AI тэмдэглэл](../../papers/06-evaluation-interface-method-notes.mn.md)-ээс хайлтын төстэй байдал, хариултын зөв байдал, эшилсэн эхийн дэмжлэгийг тусад нь авч үзсэн. UI чадвараа тодорхой харуулж, draft харахыг илэрхий үйлдэл болгосон. Автомат Монгол judge, LLM дуудалт, хэрэглэгчийн туршилт хийсэн гэж тайлагнахгүй.

Хязгаарласан нэр/оны тодруулга, татгалзал болон STT/TTS холбоос хэрэгжсэн. Дараагийн ажил нь эх/fact/FAQ-ийн өргөтгөл, асуултын хувилбарууд, optional LLM-ийн ижил өгөгдөлтэй харьцуулалт, бодит төхөөрөмж/орчны ажиллагаа. [11.10-ны шинэ төлөвлөгөө](../../CORE/ROADMAP-PROGRESS.mn.md)-г мөрдөнө; эх roadmap түүхэн эхээр хадгалагдана.


## Албан сайтын шинэ эхийн хайлт

Demo-ийн «Албан сайтаас татсан мэдээлэл» хэсэг нь curated FAQ-аас тусдаа
`CORE/database/website.db`-ийн **72 хуудас/153 chunk**-аас BM25 хайдаг.
«Сургуулийн ажлын цаг» гэж хайвал хэрэглэгчийн зөвшөөрсөн албан эхийн excerpt,
URL, хувилбар, татсан огноо normal горимд гарна. Хөгжүүлэгчийн draft сонголт тусдаа.
Энд автомат answer үүсгэхгүй, LLM дуудахгүй.

Нэг PDF, дөрвөн журмын зураг эх файлаар хадгалагдсан; доторх текстийн
боловсруулалт дуусаагүй. Шинэ corpus дээр E5/чанарын шинэ хэмжилт хийсэн гэж үзэхгүй.
Шинэ clone-д эхийн DB байхгүй тул тусдаа цуглуулна:

```powershell
py -3.11 CORE/website_corpus.py collect
py -3.11 CORE/website_corpus.py status
```

Цуглуулга нь интернет хэрэглэж, шинэ snapshot/локал DB үүсгэнэ; сургуулийн баталгаа
олгохгүй. [CORE төв](../../CORE/README.mn.md) · [Эхийн дэлгэрэнгүй](../../CORE/WEBSITE-DATA.mn.md).


## Асуултын замыг турших

Demo-ийн «Асуултын замыг шалгах» хэсгээс жишээг сонгоно:

1. **Холбоо барих утас хэд вэ?** — normal горимд бүртгэлтэй exact асуултын
   албан эхтэй A хариулт гарна; тусдаа draft сонголт хэрэггүй.
2. **ARC хамтын ажиллагаанд ямар хичээлүүд багтсан бэ?** — он/улирлын хүрээг тодруулна.
3. **2027 оны ARC хамтын ажиллагаанд ямар хичээлүүд багтсан бэ?** — өөр оны эхийг
   тааж шинэчлэхгүй; одоогийн хүрээгээр хариулахгүй.
4. **Гадаад паспорт яаж сунгах вэ?** — энэ curated санд эхтэй хариулт байхгүй;
   LLM рүү шууд дамжуулахгүй.

Замын code/шалтгаан, хадгалсан эх, дүрэм шалгасан latency харагдана.
Энэ latency нь DB/дүрэм/хайлт, бүтэн дууны pipeline биш. API нь `/api/route`;
зөвхөн query/allow_draft хүлээн авна, DB-г өөрчлөхгүй.
Чиглүүлэлтийн mapping нь хөгжүүлэлтийн proposed, хүний gold биш.
