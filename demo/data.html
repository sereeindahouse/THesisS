Урсгалын тайлбарыг үгээр унших
  1. 1

    Эхийг хадгална

    Албан сайтын HTML, сонгосон PDF ба зураг, нэмэлт табын текстийг URL, хувилбар, хадгалсан огноотой нь бүртгэнэ. Ресепшний мэдээлэл хараахан ороогүй.

    Албан эх → SQLite · эхийн хуулбар
  2. 2

    Асуултыг чиглүүлнэ

    Бүртгэлтэй баримт, FAQ, багшийн танилцуулгаар шууд хариулж болохыг шалгана. Хүрээ тодорхойгүй бол лавлаж, эхгүй бол мэдээлэл хүрэлцэхгүйг хэлнэ.

    Шууд хариулт · тодруулга · эхтэй хайлт
  3. 3

    RAG эхийн хэсгүүдийг олно

    BM25 үгийн тохирлыг, E5 утгын ойролцоог хайна. RRF хоёр эрэмбийг нэгтгэж, асуултад хамаарах нэр дэвшигч хэсгүүдийг бэлдэнэ.

    BM25 + E5 → RRF → эхийн хэсгүүд
  4. 4

    Дүрэм хариултад хэрэгтэй хэсгийг сонгоно

    Давхар, утас шиг нэг зүйл асуувал тухайн мөрийг шууд гаргана. Бусад үед BM25-ын оноогоор эхлэн 1, 2, 3 хэсгийн хослолыг шалгаж, эхийн шалгалтад тэнцсэн эхнийхийг сонгоно. Gemma үндсэн тохиргоогоор унтраалттай.

    LLM дуудлага 0 · Эхийн үгийг өөрчлөхгүй
  5. 5

    Сервер эхийн үгийг хариултад оруулна

    Сонгосон ID, эхийн холбоос, нөхцөл ба шаардлагатай талбаруудыг шалгаж, хадгалсан эхийн текстийг үгчлэн үзүүлнэ. Буруу хэсэг сонгосон алдаа үлдэх боломжтой.

    Сонгосон ID → шалгалт → эхтэй хариулт
  6. 6

    Хариултыг сонсоно

    Edge TTS хариултын текстийг дуу болгоно. Дуугаар асуух үед Gemini 3.5 Transcribe эхлээд яриаг текст болгоно.

    Микрофон → STT → асуулт · хариулт → TTS → дуу

Таньсан текстийг хэрэглэгч гараар засаж болно.
