# paper20 — Like Having a Really Bad PA: The Gulf between User Expectation and Experience of Conversational Agents

Ewa Luger; Abigail Sellen, 2016. [Анхдагч эх](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/08/p5286-luger.pdf). Ангилал: Интерфэйс; гол 20.

**Нягталсан хүрээ:** Анхдагч эхийн нэр, хэвлэлийн мэдээлэл, хураангуйг шалгасан. Metadata/Abstract-ийн эхний шалгалт. Бүтэн өгүүллийн уншлага дуусаагүй; хэрэглэгч энэ өгүүллийг уншсан тухай баталгаа хараахан байхгүй.

Аргын эхний ойлголт: Conversational agent хэрэглэгчдийн ярилцлагаар хүлээлт ба бодит чадварын зөрүүг судалсан.

Хязгаар: Тэр судалгааны оролцогч/төхөөрөмж Монгол сургуулийн ресепшний орчин биш.

Манай шийдвэр/туршилтын үндэслэл: Хэрэглэгчид дууны алдааг засах, хүрээг ойлгох, task success ба бэрхшээлийг тайлагнах боломжтой UI хэрэгтэй.

Гүн уншлагад нөхөх зүйл: өгөгдөл/split, baseline, хэмжүүрийн дүрэм, үр дүнгийн хүснэгт, хэрэгжилтийн ялгаа; дүгнэлт бүрийг яг хэсэгтэй нь холбоно. Өгүүллийн тоог бүрдүүлснийг уншлага эсвэл манай системийн чанар дууссан гэж үзэхгүй.
