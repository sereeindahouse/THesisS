# paper18 — RAGAs: Automated Evaluation of Retrieval Augmented Generation

Shahul Es; Jithin James; Luis Espinosa-Anke; Steven Schockaert, 2024. [Анхдагч эх](https://aclanthology.org/2024.eacl-demo.16/). Ангилал: Үнэлгээ; гол 20.

**Нягталсан хүрээ:** §3: эхтэй нийцэл, хариулт/контекстийн хамаарал болон автомат үнэлэгчийн хязгаарлалтыг нягталсан. Сонгосон аргын хэсгийг мөн нягталсан. Бүтэн өгүүллийн уншлага дуусаагүй; хэрэглэгч энэ өгүүллийг уншсан тухай баталгаа хараахан байхгүй.

Аргын эхний ойлголт: Faithfulness, answer relevance, context relevance-ийг LLM шүүлтээр ялгаж хэмждэг.

Хязгаар: LLM judge/prompt-н хамаарал; өгүүллийн туршилт Монгол school corpus-д давтан хийгээгүй.

Манай шийдвэр/туршилтын үндэслэл: Тусдаа хэмжүүрийн rubric ашиглана; автомат judge-г үнэн gold болгон хэрэглэж эхлээгүй.

Гүн уншлагад нөхөх зүйл: өгөгдөл/split, baseline, хэмжүүрийн дүрэм, үр дүнгийн хүснэгт, хэрэгжилтийн ялгаа; дүгнэлт бүрийг яг хэсэгтэй нь холбоно. Өгүүллийн тоог бүрдүүлснийг уншлага эсвэл манай системийн чанар дууссан гэж үзэхгүй.
