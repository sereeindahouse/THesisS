# paper14 — Multilingual E5 Text Embeddings: A Technical Report

Liang Wang et al., 2024. [Анхдагч эх](https://arxiv.org/html/2402.05672v1). Ангилал: Хайлт/RAG; гол 20.

**Нягталсан хүрээ:** §2–3, Хүснэгт 4/6, Хавсралт A болон сонгосон model card-ийн ашиглах зааврыг нягталсан. Сонгосон аргын хэсгийг мөн нягталсан. Бүтэн өгүүллийн уншлага дуусаагүй; хэрэглэгч энэ өгүүллийг уншсан тухай баталгаа хараахан байхгүй.

Аргын эхний ойлголт: Олон хэлний contrastive pretraining, labeled fine-tuning, small/base/large embedding; retrieval benchmark.

Хязгаар: MIRACL-ийн хэлүүдэд Монгол байхгүй; олон хэлтэй model card нь манай Монгол асуултын чанарын баталгаа биш.

Манай шийдвэр/туршилтын үндэслэл: Pinned small model-ийг query:/passage:, masked mean/L2 pooling-аар локал CPU дээр туршина; similarity probability биш.

Гүн уншлагад нөхөх зүйл: өгөгдөл/split, baseline, хэмжүүрийн дүрэм, үр дүнгийн хүснэгт, хэрэгжилтийн ялгаа; дүгнэлт бүрийг яг хэсэгтэй нь холбоно. Өгүүллийн тоог бүрдүүлснийг уншлага эсвэл манай системийн чанар дууссан гэж үзэхгүй.
