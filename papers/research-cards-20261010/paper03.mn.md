# paper03 — Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks

Patrick Lewis et al., 2020. [Анхдагч эх](https://arxiv.org/abs/2005.11401). Ангилал: Хайлт/RAG; гол 20.

**Нягталсан хүрээ:** §2.1–2.4-ийн арга болон §4.5-ийн индекс шинэчлэх хэсгийг нягталсан. Сонгосон аргын хэсгийг мөн нягталсан. Бүтэн өгүүллийн уншлага дуусаагүй; хэрэглэгч энэ өгүүллийг уншсан тухай баталгаа хараахан байхгүй.

Аргын эхний ойлголт: DPR retrieval ба BART генераторыг индекстэй холбож, эх судалгаанд end-to-end fine-tuning хийсэн.

Хязгаар: Тэдний QA benchmark Монгол сургуулийн системийн чанарыг батлахгүй.

Манай шийдвэр/туршилтын үндэслэл: Сургуулийн эхийн индекс/хувилбар ба neural weights-ийг ялгана; C генераци зөвхөн бодит хэрэгцээнд.

Гүн уншлагад нөхөх зүйл: өгөгдөл/split, baseline, хэмжүүрийн дүрэм, үр дүнгийн хүснэгт, хэрэгжилтийн ялгаа; дүгнэлт бүрийг яг хэсэгтэй нь холбоно. Өгүүллийн тоог бүрдүүлснийг уншлага эсвэл манай системийн чанар дууссан гэж үзэхгүй.
