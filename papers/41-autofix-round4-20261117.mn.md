# Автомат засварын 4-р тойрог: лавлах алба, дагалдах асуулт, ажилтны утас (2026.11.17)

**Хэрэглэгчийн хүсэлт (11/17, орой).** «Алдаагаа өөрөө олоод, засаад, дахиад алдаа гарвал өөрөө мэдээд засаад… надаас хамааралгүй хий; бүх зөвшөөрөл өгч байна», «наадхаа хий» (өмнөх хариуны санал: «ресепшнээс асууна уу»-гийн оронд хариуцсан албыг заах), skill: `/thesis-debug`, `/code-review`, `/engineering:code-review`, `/anthropic-skills:deep-research`.

**Товч.** Асуух шалтгаан нь өөрийн дүрэм байсан («том өөрчлөлтийн өмнө төлөвлөгөө үзүүлж зөвшөөрөл ав», «санал + "үзүүлэх үү?"») — CLAUDE.md-д «Автомат засварын гогцоо» дүрэм, `/thesis-autofix` skill нэмж зассан. Энэ тойрогт 11 асуудлыг олж засав; хоёр нь ноцтой: (1) **ажилтны 8 оронтой гар утас хариултад харагдаж байсан** (тэнхимийн утсыг асуухад), (2) **«Сургуулийн захирал хэн бэ?» өөр их сургуулийн захирлын мэдээг** харуулж байсан. Хэмжилтийн дүн §4-т.

## 1. Арга

1. Эх сурвалж: өмнөх тойргийн «засаагүй» жагсаалт, W04/W04-b/ноорог багцын tune хэсгийн алдаа, шинэ туршилтын асуулт (`runtime/eval/probe-bank-round4-20261117.json`: 28 дан асуулт + 14 дагалдах хос; 3-р тойргийн 82 асуулт дахин). Test хэсгийг харж тааруулаагүй.
2. Алдаа бүрт эхний буруу шатыг (`/thesis-debug`): асуулт ойлгох → хайлт → сонголт → утгын төрөл → ресепшний хүснэгт → харагдах/уншигдах текст.
3. Хэмжилт: `tools/run_config_comparison.py` (ижил өгөгдөл, `.venv-modeltools`, LLM 0); хэмжилт явж байхад код засаагүй. Туршилтын асуултыг хувийн серверээр (`tools/probe_questions.py`) өмнө/дараа нь асууж мөр бүрээр тулгав.
4. Судалгаа (`/anthropic-skills:deep-research`, 3 судлаач + тайлан бичигч): `reports/Автомат гогцоо ба дагалдах асуулт.md` (→ `МИНИЙ-ДИПЛОМ/06_Систем/Автомат_гогцоо_ба_дагалдах_асуулт.md`). Агент уншсан; хэрэглэгч уншсан гэж тэмдэглэхгүй.

**Судалгаанаас (дагалдах асуулт).** CAsT 2019 (Англи): зөвхөн одоогийн асуулт NDCG@3 0.155, бүх түүх залгах 0.256, анхны асуултыг нэмэх 0.282, сургасан үг сонгогч 0.341, хүний дахин бичсэн 0.361 (QuReTeC, Table 7); бүх түүх залгах нь сонгомол дамжуулалтаас муу; бие даасан асуултыг буруу дахин бичих 2–29%. Иймд «бие даасан бол хөндөхгүй, сүүлийн нэрийг л нэм, ил харуул, хугацаатай» гэсэн дүрэм сонгосон (тайлангийн §Б). Монгол/ресепшний нотолгоо байхгүй — бодит дагалдах хосын багцаар хэмжих нь дараагийн ажил.

## 3. Залруулга ба регресс

- №5-ын анхны хувилбар гарчгийг утгын төрөлгүй асуултад ч хамруулж, W04-A14-ийг хоёр хуудасны хамааралгүй хэсгээс залгаж хариулсан — туршилтаар олж, гарчгийг зөвхөн утгын төрөл асуусан асуултад хязгаарласан.
- №5 нь тоон асуултад «17 оюутан хамгаалсан» гэсэн шинэ буруу хариу гаргасныг туршилтын асуултаар олж №7-оор зассан.
- №2: өмнөх тойргуудын тайланд «ажилтны утсыг харуулахгүй» гэж бичсэн ч энэ нь зөвхөн ресепшний хүснэгтэд хамаарч байсан; сайтын хуудасны утас хариултад гарч байсныг энэ тойрогт анх илрүүлэв.

## 5. Засаагүй (шалтгаантай)

- «2-р курст шилжиж орж болох уу?» — одоо ойлгомжгүй тодруулгын оронд «олдсонгүй» + Сургалтын алба гэнэ; «2-р курс шилжин · 4 жил» мөр «орж» үггүй тул сонгогдоогүй (ижил утгатай үгийн жагсаалт хэрэгтэй).
- «Оюутны зөвлөлийн дарга хэн бэ?», «Сургуулийг хэн үүсгэн байгуулсан бэ?» — хамааралгүй хэсэг харуулдаг (хүний нэрийн утгын төрөл дараагийн тойрогт).
- «Сургалтын төлбөр хэрхэн төлөх вэ?» — олимпиадын хөнгөлөлтийн текст (HEAD-д ч ижил).
- S02 «Барилга»/«Барилгын» — үнэлгээний үгчилсэн тулгалт; хариуг харсны дараа шалгуурыг өөрчлөхгүй.
- Албадын ажлын цаг (хэрэглэгч 11/16: 08:00–17:00) — «оруулахаас өмнө асуу» гэсэн тул оруулаагүй.
- Сэдэв → албаны холбоос (`config/referral.json`) — агент албаны нэрээр тааварласан, хэрэглэгч/сургууль хянаагүй.
- Chrome өргөтгөл холбогдоогүй — дэлгэцээр шалгаагүй; дагалдах асуултын хуудасны хэсгийг HTTP-ээр л шалгав.
