# Шинэ хэлэгчийн STT хэмжилтийн бэлтгэл

Энэ багц нь өөр 2–3 хүнээс **шинэ** бичлэг ирэхэд `gemini-3.5-transcribe`-ийг
хэмжихэд бэлтгэнэ. Одоогоор шинэ хэлэгч, зөвшөөрөл, бичлэг бий болсон гэж
тооцохгүй. Сургалт хийхгүй; шинэ хэлэгчийн ерөнхий accuracy-г урьдчилж амлахгүй.

## 1. Бичлэгээ цуглуулах

1. [Зөвшөөрлийн маягт](consent.mn.md)-ыг хүнтэй тайлбарлаж бөглөнө. Дууг Google
   рүү илгээх зөвшөөрөл нь локал бичлэг хийх зөвшөөрлөөс тусдаа.
2. Хүн бүрт өмнө хэрэглээгүй `speaker_code` өгнө. Нэг хүнийг өөр кодоор олон
   хүн болгож тоолохгүй. Хуучин 12 клип эсвэл өмнөх хэлэгчийг шинэ нэрээр оруулахгүй.
3. Эхлээд нэг хүнд [15 асуултаас](questions.mn.md) 3–6-г уншуулж, бичлэгийн
   чанарыг шалгаад үргэлжлүүлж болно. Боломжтой бол ижил асуултыг өөр хүмүүсээр
   уншуулна; дутууг бодит тоогоор нь тайлагнана.
4. Нэг клипэд нэг асуулт, ердийн хурдаар, эхлэл/төгсгөлийг таслахгүй бичнэ.
   Зорилтот урт 5–15 секунд; runner 0.5–30 секундыг хүлээн авна. Урт бол үгийг тасалж хасахын
   оронд дахин бичнэ. Цуурай, чимээ, тасарсан үг байвал тэмдэглэж нягтална.
5. WAV, PCM 16-bit, mono хэлбэрээр бэлтгэнэ. 8–48 kHz зөвшөөрнө; 16 kHz-ийг
   илүүд үзнэ. Эх WAV-ийг runner өөрчлөхгүй. Эх бичлэгийг хувийн багцдаа хадгалж,
   нэрийг нь хүний жинхэнэ нэрээр өгөхгүй.
6. Хүн аудиогоо сонсоод яг хэлснээ `reference_text`-д бичиж батална. Асуултын
   картыг шууд хуулсан текст, AI draft, Gemini-ийн гаралт нь баталсан reference биш.
   Уншихдаа давтсан/өөрчилсөн үгийг мөн тэмдэглэнэ. Reference-ийг model output
   харахаас өмнө батална.

## 2. Хувийн manifest

`manifest.example.json` нь **ажиллуулахад бэлэн өгөгдөл биш**.
`new_speakers_confirmed=false`, `consent=false`, хоосон reference, байхгүй WAV
замтай. Зөвшөөрөл/reference/файлын дутуу нөхцөлүүдийг шалгалт татгалзана.

Жишээг `runtime/stt-new-speakers-YYYYMMDD/manifest.json` руу хуулж,
`YYYYMMDD`-г бодит огноогоор солино. Жишээ бүтэц:

```text
runtime/stt-new-speakers-YYYYMMDD/
  manifest.json
  audio/
    sp01-q01.wav
    sp02-q01.wav
  consent/                 # бөглөсөн маягт, хувийн
```

Дээд талын `new_speakers_confirmed` нь **операторын бодит баталгаа**: хүмүүс нь
өмнөх хэлэгчээс өөр, бичлэг нь шинэ гэдгийг хүн нягталсны дараа л `true` болгоно.
Код эсвэл шинэ файлын нэр нь хүний шинэ identity-г батлахгүй. Runner хуучин
manifest-ийн hash metadata-тай давхцсан аудиог шалгана; хуучин аудиог нээхгүй.
Hash давхцахгүй байсан ч өөр хүн ярьсныг биометрээр нотолсон гэсэн үг биш.

`clips` дотор бодит клип бүрт нэг мөр нэмнэ. `audio_path` нь manifest байгаа
хавтсаас тооцсон харьцангуй зам бөгөөд тэр судалгааны хавтсаас гадагш гарахгүй.
`clip_id` давхцахгүй, `speaker_code` нэг хүнийг
тогтвортой заана. `question_id` нь Q01–Q15. `reference_text` бол сонсож баталсан
текст. Дуу дамжуулах зөвшөөрлийг бодитоор авсан үед л `consent=true` болгоно.
Жишээний `sp01` кодыг бодит шинэ хүнтэй холбохдоо өмнөх хэлэгчийн кодтой
давхцахгүйг шалгана. Маягт, аудио, manifest, reference, түлхүүрийг нийтлэхгүй.

## 3. Эхлээд илгээхгүй шалгах

Төслийн үндсэн хавтсаас, бэлэн Python орчинд:

```powershell
.venv-modeltools/Scripts/python.exe -B -X utf8 tools/measure_new_speaker_stt.py --manifest runtime/stt-new-speakers-YYYYMMDD/manifest.json --dry-run
```

`--dry-run`, эсвэл `--execute`-гүй энгийн команд нь зөвшөөрөл, WAV, хугацаа,
reference-ийн нөхцөлийг **офлайнаар** шалгана; аудио илгээхгүй, түлхүүр шаардахгүй.
Файл/reference зөв байсан ч `new_speakers_confirmed=false` бол илгээхэд бэлэн
гэж үзэхгүй (`ready=false`). Шалгалт тэнцсэн нь бодит API run эсвэл чанарын
ахиц болсон гэсэн үг биш. Алдаатай мөр байвал засаж дахин шалгана;
байгаа raw дүнг дарахгүй.

## 4. Бодит хэмжилт ирээдүйд

Оператор provider-ийн тухайн үеийн нөхцөл, Free tier, хүний зөвшөөрлийг
нягталсны дараа л бодит илгээх шийдвэр гаргана. Энэ бэлтгэлийн ажилд API
дуудаагүй. Доорх нь **ирээдүйн бодит илгээх командын загвар; одоо ажиллуулаагүй**:

```powershell
.venv-modeltools/Scripts/python.exe -B -X utf8 tools/measure_new_speaker_stt.py --manifest runtime/stt-new-speakers-YYYYMMDD/manifest.json --execute --free-tier-confirmed
```

`--free-tier-confirmed` нь операторын $0/Free tier баталгаа; billing-ийг
программ автоматаар шалгасан эсвэл provider төлбөр авахгүй гэсэн баталгаа биш.
Түлхүүрийг команд, manifest, screenshot эсвэл тайланд оруулахгүй.

Runner хоёр гар ашиглана: v2 жагсаалттай эх WAV, мөн ижил жагсаалттай цэгцэлсэн
WAV. N клипийн **танилтын оролдлогын** дээд тоо 2N. Upload болон цэвэрлэх
хүсэлтийг оруулсан HTTP дээд тоо 8N; хоёр тоог нэг хэмжүүр гэж тайлагнахгүй.
Эхний 429-д шинэ танилтын оролдлогыг зогсооно. Өмнө upload хийсэн файлыг
цэвэрлэх нэг оролдлого гарч болно. Автомат retry болон төлбөртэй fallback байхгүй.

Оператор дараа нь зориуд үргэлжлүүлэхдээ дээрх команд дээр `--resume` нэмнэ.
Энэ нь амжилтгүй, тасалдсан, 429 болсон зэрэг **аль хэдийн оролдсон бүх гарыг**
дахин дуудахгүй. Зөвхөн огт оролдоогүй үлдсэн гаруудыг эх run-ийн нийт 2N
танилт/8N HTTP хязгаарт багтааж үргэлжлүүлнэ. Алдаатай гаралт дутагдсан хэвээр
үлдэнэ; хоосон амжилттай transcript болгож нөхөхгүй.

Дүнг хүн бүрээр болон нийтээр салгана. Нэг хүнд цэгцлэлт муу нөлөөлсөн бол
нийт дундажид нуухгүй. Reference-ийн үгээр хэлсэн он ба provider-ийн цифрийг
утгаар нь үзэх хэмжүүрийг strict WER/CER-ээс тусад нь тайлагнана. Өөрсдөө
бэлтгэсэн уншлагын 15 асуулт тул чөлөөт яриа, бүх шинэ хэрэглэгчийн чанарын
баталгаа гэж үзэхгүй. Шинэ бичлэгийг жин сургахад ашиглахгүй.

## 5. Raw дүн ба resume

Raw гаралт тухайн судалгааны `measurement/` дотор: protocol ба manifest snapshot,
`attempts.jsonl` append-only journal, `attempt-state.json` дуудлагын тоолуур,
`scores-private.json`, `summary.json`. Summary нь нийлбэр/хэлэгчийн кодтой тоо;
transcript/reference хэвлэхгүй. Эх WAV болон config-ийг өөрчлөхгүй.

Resume нь manifest/reference/consent, аудио, vocabulary, cleaner/кодын hash
өөрчлөгдвөл зогсоно. Journal эсвэл тоолуурыг устгаж төсвийг шинэчлэхгүй;
эвдэрсэн үед автоматаар дахин илгээхгүй. Процесс тасарсан үед дууссан HTTP-ийн
тоо дутуу байж болох тул бүртгэгдсэн тоо ба дээд хязгаарыг тусад нь харуулна.
Түлхүүрийг зөвхөн ирээдүйн explicit execute үед байгаа private DPAPI хадгалалт
эсвэл `GEMINI_API_KEY` орчноос авна; утгыг энд бичихгүй, raw файлд хадгалахгүй.
