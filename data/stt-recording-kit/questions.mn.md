# Шинэ хэлэгчийн STT бичлэгт унших 15 асуулт

Эдгээр нь дуу танилтыг шалгахаар **шинээр зохиосон асуулт**. Сургуулийн
баримт, хариултын gold эсвэл хүний хэлсэн үгийн reference биш. Сэдвийн холбоог
`config/knowledge-topics.json`-оос авсан; эхгүй өрөө/хуваарийн асуултад систем
заавал хариулна гэж үзэхгүй. Нөхцөлөөр хэлсэн мөнгөн дүн нь бодит хураамжийн
мэдэгдэл биш.

Асуултын мөрийг л ердийн хурдаар уншина. `Q01` болон сэдвийн кодыг дуудахгүй.
Аль нэг үгийг өөрөөр хэлсэн, давтсан эсвэл орхисон бол сонсож батлах
`reference_text`-д **яг хэлснээ** бичнэ; доорх мөрийг шууд хуулж батлахгүй.

| Код | Сэдэв (`topic_id`) | Унших асуулт |
|---|---|---|
| Q01 | `school.overview` | Шинэ Монгол Коосэн ямар чиглэлийн сургалт явуулдаг вэ? |
| Q02 | `admissions.requirements` | Хоёр мянга хорин зургаан оны элсэлтийн шаардлагыг хаанаас харах вэ? |
| Q03 | `admissions.fees` | Хэрэв бүртгэлийн хураамж хорин мянган төгрөг гэж заасан бол ямар аргаар төлөх вэ? |
| Q04 | `admissions.exams` | Бичгийн шалгалт, эссэ, ярилцлагын дараалал ямар вэ? |
| Q05 | `academics.general` | Ерөнхий эрдмийн тэнхимийн хоёр мянга хорин дөрвөн оны багшийн тоо эхэд байна уу? |
| Q06 | `academics.computer-science` | Компьютерын ухааны тэнхимд ямар хичээл, лаборатори байдаг вэ? |
| Q07 | `academics.chemical` | Химийн инженерийн тэнхимийн хөтөлбөрийг хаанаас харж болох вэ? |
| Q08 | `student.library` | Номын сан хэддүгээр давхарт байдаг, хэзээ ажилладаг вэ? |
| Q09 | `career.partners` | ARC болон Sakura гэсэн нэртэй хамтын ажиллагааны мэдээлэл хадгалсан эхэд байна уу? |
| Q10 | `news` | Хоёр мянга хорин таван онд нийтэлсэн дадлагын мэдээнд ямар байгууллага нэрлэсэн бэ? |
| Q11 | `events` | Шинжлэх ухааны олимпиадын бүртгэлийн хугацаа, насны ангилал ямар байсан бэ? |
| Q12 | `contact` | Сургуулийн ерөнхий утас, имэйл болон ажлын цагийн мэдээллийг хэлж өгнө үү? |
| Q13 | `location.departments` | Барилгын дэд бүтцийн инженерийн тэнхимийн өрөө хэддүгээр давхарт вэ? |
| Q14 | `staff.directory` | Цахилгаан электроникийн инженерийн тэнхимийн багш нарын нэр, албан тушаалын жагсаалт бий юу? |
| Q15 | `classes.timetable` | Хоёрдугаар курсын бүлгийн даваа гаргийн эхний хичээл хэдэн цагт, ямар өрөөнд орох вэ? |

15 асуулт нь 11 үндсэн хүрээ, 15 өөр сэдэвтэй. Нэрийг Монгол эсвэл латин
үсгээр өөрөөр хэлсэн бол reference-д сонсогдсон хэлбэрийг нь тэмдэглэнэ.
Хүний нэрийг шинээр зохиож оруулаагүй; сургуулийн нэр, тэнхимийн нэр, ARC/Sakura
гэсэн нийтийн тохиргоонд байгаа нэрсийг ашигласан.
