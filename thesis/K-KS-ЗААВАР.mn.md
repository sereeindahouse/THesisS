# K ба KS бичвэрийг хаанаас засах вэ

**K** — багш мэддэг, багшид харагддаг бичвэр. **KS** — багшид харуулахгүй, агентын ажлын тэмдэглэл.
Та K-г засна. KS-ийг агент бичдэг. KS-ийг засах шаардлагагүй, харин уншиж болно.

## K — та засна (багшид харагдана)

| Юу | Засах файл | Хаанаас нээх |
|---|---|---|
| 1-р бүлэг: Удиртгал | `Chapter1_Introduction.tex` | `МИНИЙ-ДИПЛОМ/01_Диплом/LaTeX_бичвэр/Chapters/` |
| 2-р бүлэг: Онол, өнөөгийн түвшин | `Chapter2_Literature.tex` | мөн адил |
| 3-р бүлэг: Арга зүй | `Chapter3_Methodology.tex` | мөн адил |
| 4-р бүлэг: Үр дүн | `Chapter4_Results.tex` | мөн адил |
| 5-р бүлэг: Цаашдын ажил | `Chapter5_Conclusion.tex` | мөн адил |
| Нүүр (нэр, удирдагч, он) | `Information.tex` | `МИНИЙ-ДИПЛОМ/01_Диплом/LaTeX_бичвэр/` |
| Зургийн доторх үг | `Figures/*.tex` (жишээ нь `system_structure.tex`) | `МИНИЙ-ДИПЛОМ/01_Диплом/LaTeX_бичвэр/Figures/` |
| Үзлэгийн слайд | `34_Үзлэг1_ШМТК_v110b.pptx` — PowerPoint эсвэл Canva дээр | `МИНИЙ-ДИПЛОМ/02_Семинар/` |
| Ярих бичвэр | `34_Яриа_Үзлэг1_2026-12-01.mn.md` | `МИНИЙ-ДИПЛОМ/02_Семинар/` (эх нь `CORE/seminar-2026-12-01/`) |

Бүлгийн файл бүр дараах хоёр мөрөөр эхэлнэ: `% K — БАГШИД ХАРАГДАНА …`.

**Засахдаа:**
- `%`-гүй мөр бүр PDF-д хэвлэгдэнэ. `%`-ээр эхэлсэн мөр зөвхөн тэмдэглэл бөгөөд хэвлэгдэхгүй.
- Зөвхөн өгүүлбэрийг засна. Дараах тушаалуудад хүрэхгүй: `\section{…}`, `\label{…}`, `\ref{…}`, `\cite{…}`, `\tref{…}`, `\fref{…}`. Тэдгээр нь гарчиг, иш татах дугаарыг холбодог.
- `\textbf{…}` нь тод үсэг, `«…»` нь хашилт.
- Хадгалсны дараа надад «PDF гарга» гэж хэлээрэй. Эсвэл командыг өөрөө ажиллуулж болно: `.venv/Scripts/python.exe tools/build_thesis_pdfs.py`. Би PDF-ийг гаргаад, Word файл, слайд, ярианд холбогдох газрыг хамт шинэчилнэ.
- LaTeX засахад хэцүү бол `МИНИЙ-ДИПЛОМ/01_Диплом/Диплом_1_багшид_үзүүлэх.docx` дээр Word-ийн тайлбараар (Review → New Comment) тэмдэглээд надад өгөөрэй. Би тэр засварыг LaTeX руу оруулна. Word файлыг шууд засаад орхивол засвар PDF-д орохгүй, учир нь эх бичвэр нь LaTeX юм.
