# Дипломын бичвэр (LaTeX)

Энэ хавтас бол дипломын бичвэр. Загварыг өмнөх оюутны [Asura-lab/diplom](https://github.com/Asura-lab/diplom) repo-оос авсан. Удирдагч багш энэ загварыг ашиглахыг зөвлөсөн. `Thesis.cls` болон нүүр хуудсууд загвараас өөрчлөгдөөгүй.

## Файлууд юу хийдэг вэ

| Файл | Үүрэг |
|---|---|
| `main.tex` | Үндсэн файл. Бүх бүлгийг дарааллаар нь холбоно. Үүнийг хөрвүүлнэ. |
| `Information.tex` | Нэр, оюутны код, удирдагч, сэдвийн нэр. **Улаан хаалттай хэсгийг өөрийнхөөрөө солино.** |
| `Thesis.cls` | Хуудасны хэмжээ, захын зай, гарчгийн хэлбэр (загвараас). |
| `Chapters/plan.tex` | Ажлын төлөвлөгөө (долоо хоногоор). |
| `Chapters/Chapter1_Introduction.tex` | 1. Удиртгал: зорилго, зорилт, судалгааны асуулт. |
| `Chapters/Chapter2_Literature.tex` | 2. Онол: Whisper, Gemini (бичигдсэн), RAG (уншсаны дараа). |
| `Chapters/Chapter3_Methodology.tex` | 3. Арга зүй: системийн бүтэц, мэдлэгийн мод, харьцуулалтын арга. |
| `Chapters/Chapter4_Results.tex` | 4. Үр дүн: Whisper–Gemini хэмжилт. |
| `Chapters/Chapter5_Conclusion.tex` | Дүгнэлт (4-р бүлгийн төгсгөл). |
| `references.bib` | Ном зүй. `\cite{түлхүүр}`-ээр иш татна. |

## Өнгөт тэмдэглэгээ (засах зүйлс)

- **Улаан `[Шалгах: ...]`** — эх хувьтай тулгах, шийдэх зүйл.
- **Цэнхэр `[Бичнэ: ...]`** — дараа бичих хэсэг.
- **Улбар шар `[унших]`** — иш татсан ч та өөрөө хараахан уншаагүй өгүүлэл. Уншсаны дараа тухайн `\unshih`-ийг устгана.

Эцсийн хувилбарт `main.tex` доторх `\zasvartrue`-г `\zasvarfalse` болговол бүх тэмдэглэгээ нуугдана.

## Хөрвүүлэх (PDF гаргах)

**VS Code дээр (санал болгох):**
1. [MiKTeX](https://miktex.org/download) суулгана. Шаардлагатай package-ийг анх хөрвүүлэхэд өөрөө татна.
2. VS Code-д **LaTeX Workshop** өргөтгөл суулгана.
3. `thesis/main.tex`-ийг нээгээд хадгална (Ctrl+S). Файлын эхний мөрөнд `% !TEX program = xelatex` байгаа тул XeLaTeX-ээр хөрвүүлнэ.

**Командаар:** `cd thesis` → `latexmk main.tex` (`latexmkrc` нь XeLaTeX-ийг сонгоно).

**Overleaf:** хавтсыг zip болгож оруулаад Compiler-ийг **XeLaTeX** болгоно. Overleaf-д Times New Roman байхгүй тул түүнтэй ижил хэмжээтэй Liberation Serif фонт автоматаар хэрэглэгдэнэ.

Times New Roman 11pt, A4 нь сургуулийн шаардлага (гарын авлага х.9). Windows дээр Times New Roman автоматаар сонгогдоно.
