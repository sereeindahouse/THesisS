# Шинэ Монгол Коосэний мэдлэгийн мод

**[Холбоостой мэдлэгийн модыг төсөл дотроос нээх →](http://127.0.0.1:8765/data#tree)**

2026.10.24. Үндсэн харагдац нь сургуулийн **33 зангилаа, 32 салаалсан холбоостой SVG зураг** болсон. Шинэ Монгол Коосэн гэсэн үндсээс сургуулийн тухай, элсэлт, тэнхимүүд, оюутны амьдрал зэрэг салаа гарна. Чатны дээд талын «Мэдлэгийн мод» холбоос энэ зургийг нээнэ.

Зангилааг сонгоход тухайн сэдвийн хадгалсан эх, бүтэцтэй баримт, FAQ доор гарна. Хайлтаар тохирох зангилаа тодорч, томруулах/жижигрүүлэх, чирж зөөх, сонгосон салаанд төвлөрөх, бүтнээр харах, эхлэлд буцаах боломжтой. Эхийн холбоосоос албан хуудсыг эсвэл тухайн URL-ийн одоогийн хадгалсан HTML текстийг нээнэ. Curated эхийн хувилбар ба HTML capture хувилбар тусдаа бүртгэл тул ижил тоо байх албагүй. Гар утасны нарийн дэлгэцэд «Салаа руу очих» сонголтоор сэдэв сонгож болно; текстэн жагсаалт нэмэлтээр үлдсэн.

Мэдлэгийн модны хуудсан дахь **системийн урсгалын зураг нь 16 зангилаа, 19 чиглэсэн сумтай**. Албан эх → SQLite → BM25/E5 → RRF → Gemma → эхийн шалгалт → хариулт → TTS гэсэн холбоос, мөн микрофон → Whisper STT → асуулт гэсэн замыг харуулна. Тогтмол fact/FAQ хариултын зам Gemma-г алгасаж болно. **Gemma ашиглах эхийн хэсгийн ID-г сонгож, сервер хадгалсан эхийн үгийг хариултад оруулна.**

Системийн «тархи» гэдэг нь энд нийтэд тайлбарлаж болох эх сурвалж, өгөгдөл боловсруулах урсгалыг хэлнэ. Зураг нь нейрон сүлжээний сурсан жин эсвэл LLM-ийн дотоод бодлын дүрслэл биш. Сэдвийн мод өөрөө шинэ fact үүсгэхгүй, одоогийн RAG эрэмбийг өөрчлөхгүй.

**Шалгалтын хүрээ (2026.10.24 шинэчлэв):** Brave дээр компьютер болон хэмжсэн 374/376 CSS px нарийн харагдацыг бодитоор үзэж, хайлт, zoom, зангилааны хулганын товшилт, номын сангийн эх нээх, Whisper/Gemma-ийн тайлбар, багшийн дөрвөн карт/хоёр зургийг шалгасан. 9 эцсийн үйлдлийн шалгалт тэнцсэн. Симуляцтай DOM regression-ууд тусдаа; өмнөх PNG preview-г браузерийн screenshot гэж тооцоогүй. Шинэ хүний answer accuracy, TTS сонсголын оноо хэмжээгүй.

Сэдвийн ангиллын суурь 2026.10.23-нд үүссэн. Жишээ нь төлбөрийн асуулт «Элсэлт → Төлбөр, хураамж → тухайн он, төрлийг заасан fact/FAQ → эхийн locator» гэсэн замтай. Эхийг уншихдаа төлбөрийн он, зориулалт, нөхцөлийг хамт шалгана.

Доорх `topic_contains` холбоо нь мэдээллийн бүлэг багтааж байгааг илэрхийлнэ. Ангилал нь хөгжүүлэлтийн санал; сургуулийн албан taxonomy эсвэл хүний баталсан answer gold биш. Нэг баримт нэг ID-тай, өөр сэдэвт хамаарвал холбоосоор заагдана.

## Одоогийн RAG ба LLM-ийн үүрэг

Одоогийн чат BM25/E5/RRF эрэмбээр эх хайж, C замд Gemma эхийн ID сонгоно. Сервер exact эхийг сэргээж guard-аар шалгаад TTS-д өгдөг. Мод нь тэр эхийн санг тайлбарлах, хамралтын цоорхойг харах навигаци болсон. Энэ үеийн tree builder LLM дуудахгүй, эхийн DB болон хайлтын эрэмбийг өөрчлөхгүй.

Дараагийн retrieval өөрчлөлтийг шалгахдаа шинэ асуулт/reference-ийг гаралтаас өмнө тогтоож, ижил corpus/k/context budget дээр flat retrieval, tree routing, tree+flat fallback-ийг харьцуулна. Буруу салбар сонгож зөв эхээ алдах, бүх шаардлагатай эх олдсон эсэх, хариултын бүрэн/зөв байдал, татгалзалт, хугацааг тусад нь хэмжинэ. Мод үүссэнээр accuracy өссөн гэж тооцоогүй.
