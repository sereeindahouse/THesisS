## 2 · 🔵 Систем ба ажил — юу хаана байна?

```text
Микрофон/аудио → Cafet Whisper raw STT → ил тод санал/хэрэглэгчийн засвар
 → асуултын хүрээ → шууд fact/FAQ эсвэл BM25 + E5 + RRF
 → шаардлагатай C замд Gemma эхийн ID сонгоно
 → сервер source/field/year/condition шалгаж эхийн үгийг сэргээнэ
 → дэлгэцийн хариулт + citation → spoken-text бэлтгэл → Edge TTS → тоглуулах
```

**A/B** шууд зам Gemma дуудахгүй; **C** нь эхийн сонголт; **D** тодруулга; **E** тайлбартай татгалзалт/боломжийн хязгаар. E5 нь embedding, хариулт бичдэг генератор биш. Эхийн үг байсан ч хамаарахгүй эсвэл дутуу бол хариулт буруу байж болно. Ерөнхий олон ээлжийн LLM memory эсвэл чөлөөт тайлбар үүсгэлт гэж тайлбарлахгүй.

**Эхийн сан:** 75 HTML, нэг PDF/дөрвөн журмын зураг; 196 индекс =145 HTML +21 баримтын хэсэг +30 нэмэлт таб; бүтэцтэй 14 эхийн хувилбар,40 fact,30 FAQ. Энэ нь бүх сургуулийн мэдээлэл бүрэн гэсэн баталгаа биш. Хадгалсан огноо ба өнөөдрийн live төлөв өөр.

**Мэдлэгийн мод:** 8 хүрээ/33 сэдэв,33 зангилаа/32 салаа; эх нээх навигац, `affects_retrieval=false`. GraphRAG, сурсан жин эсвэл LLM-ийн дотоод бодол биш. Системийн тусдаа зураг16 зангилаа/19 сумтай.
