## Одоо demo дээр хийх зүйл

**DEMO.cmd** хоёр дараад:

1. **«1. Микрофоноор ярих» → «Бичлэг дуусгах»**; эсвэл файл сонгоод
   **«Файлыг таних»** дарна.
2. Таньсан текстээ засаж **«3. Замыг шалгах»** дарна. Ноорог эхийн хариултыг
   турших бол draft сонголт хийнэ; энэ нь сургуулийн баталгаа биш.
3. Батаа/Есүй сонгоод **«4. Хариултын дууг үүсгэх»**, дараа нь **▶** дарна.
   STT локал; TTS унших текстийг онлайн Edge үйлчилгээнд илгээнэ.
4. **«Үлдсэн зургаан STT, гурван TTS дууг энд нягтлах»** хэсгийг нээж сонсгол,
   бүтэн зөв текст/дуудлагын алдаагаа хадгална. Хүний илэрхий баталгаа шаардана;
   model draft-ийг автоматаар зөв гэж хадгалахгүй. Хувийн бүртгэл GitHub-д орохгүй.

Браузерын бичлэг 20 секундэд зогсоно; файл 30 секунд/8 MiB хүртэл.
**«Шинэ асуулт / цэвэрлэх»** шинэ түр аудио ба дэлгэцийг цэвэрлэнэ;
эхний WAV, хадгалсан үнэлгээг устгахгүй. [Бүрэн demo заавар](../reports/system/SQLITE-SEARCH.mn.md).
Шинэ clone-д дууны сангууд/локал жин хэрэгтэй; зөвхөн бичгэн demo model-гүй ажиллана.
