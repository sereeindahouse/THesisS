## Одоо demo дээр хийх зүйл

**DEMO.cmd** хоёр дараад:

1. **«Ярьж асуух» → «Бичлэг дуусгах»**; эсвэл файл сонгоод
   **«Файлыг таних»** дарна.
2. Таньсан текстээ засаж **«Хариулт авах»** дарна. Албан эхийн URL, татсан огноотой хариултыг харна.
3. Батаа/Есүй сонгоод **«Дуу үүсгэх»**, дараа нь **▶** дарна.
   STT локал; TTS унших текстийг онлайн Edge үйлчилгээнд илгээнэ.
4. LLM бэлэн бол засварын санал авах товчоор тусдаа санал авна.
   **«Саналыг хэрэглэх»** дарж байж текст өөрчлөгдөнө; анхны STT хэвээр.
   Хуучин үнэлгээний хэрэгсэл нэмэлт хэсэгт заавал биш байдлаар үлдсэн.

Браузерын бичлэг 20 секундэд зогсоно; файл 30 секунд/8 MiB хүртэл.
**«Шинэ асуулт»** шинэ түр аудио ба дэлгэцийг цэвэрлэнэ;
эхний WAV, хадгалсан үнэлгээг устгахгүй. [Бүрэн demo заавар](../reports/system/SQLITE-SEARCH.mn.md).
Шинэ clone-д дууны сангууд/локал жин хэрэгтэй; зөвхөн бичгэн demo model-гүй ажиллана.
