## Чатыг ашиглах

**DEMO.cmd** хоёр дарна; нээлттэй хуудас хуучин харагдвал **Ctrl+F5**.

1. Доорх бичих хэсэгт асуултаа бичээд **Enter** эсвэл **↑** дарна.
   **Shift+Enter** шинэ мөр нэмнэ. Асуулт, хариулт ярианд үлдэнэ.
2. Дуугаар асуух бол **микрофон** товч → ярина → **«Дуусгах»**.
   Эсвэл **хавчаар** товчоор аудио файл сонгоно; текст автоматаар гарна.
   Таньсан текстээ нягтлаад илгээнэ.
3. Хариултын **«Эх сурвалж»**-ийг дэлгэж URL/татсан огноог үзнэ.
   **«Сонсох»** дарж дуут хариулт авна; браузер тоглуулахгүй бол **▶**.
4. Дээд талын **«Шинэ чат» / +** яриаг цэвэрлэж, **тохиргооны** товч нэмэлт
   эх/FAQ/дууны жишээ/техникийн хэрэгслийг нээнэ. Үндсэн хэрэглээнд тохируулах шаардлагагүй.

LLM засварын модель бэлэн үед л **«Текст нягтлах»** нэмэлт товч харагдана.
Саналыг хэрэглэгч сонгож хэрэглэнэ; анхны STT өөрчлөгдөхгүй. STT засварын LLM тусдаа идэвхгүй. Эхээс хариулт бэлтгэх RAG генераторын төлөвийг техникийн хэсэгт харуулна. Чатны түүх энэ нээлттэй tab-д харагдана; үүнийг генератив LLM-ийн
чөлөөт олон ээлжийн ойлголт эсвэл моделийн сургалт гэж тайлагнахгүй.

Бичлэг 20 секундэд зогсоно; файл 30 секунд/8 MiB хүртэл. STT локал; TTS унших
текстийг онлайн Edge үйлчилгээнд илгээнэ. Шинэ clone-д дууны сан/жин хэрэгтэй;
бичгэн чат model-гүй ажиллана. [Бүрэн заавар](../reports/system/SQLITE-SEARCH.mn.md).
