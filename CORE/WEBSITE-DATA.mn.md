# NMCT албан сайтын мэдээллийн сан — 2026.10.10

[Албан сайт](https://nmct.edu.mn/)-ын нээлттэй холбоосоор crawl хийсэн бодит цуглуулалт.

| Хэмжээ | Дүн |
|---|---:|
| Амжилттай HTML URL | 72 |
| Хайлтын текстийн хэсэг | 153 |
| Эх PDF | 1 |
| Элсэлтийн журмын зураг | 4 |
| Олдсон боловч404 өгсөн холбоос | 2 |
| Автоматаар баталсан хуудас | 0 |

Хамрах хүрээ: нүүр/бидний тухай, элсэлт/олимпиад, тэнхим/хөтөлбөр, карьер,
оюутан, холбоо барих, арга хэмжээ болон зургаан мэдээний жагсаалтаас олдсон нийтлэлүүд.
URL бүрийн HTML эх, гаргасан текст, UTC татсан огноо, HTTP metadata, SHA256,
semantic version болон chunk offset хадгалсан. Сайт robots.txt/sitemap.xml нийтлээгүй (404).
Нээлттэй HTML-ийн олдсон холбоосын дарааллыг дуусгасан; limit-д тулж таслаагүй.

**«Сайтын бүх зүйл батлагдсан» гэсэн үг биш.** PDF/дөрвөн зураг эх файлаар хадгалагдсан;
тэдгээрийн доторх текстийг OCR/хүний нягталгаагаар хараахан гаргаагүй. Зөвхөн browser-ийн
tab солиход гардаг текстийг бүрэн гаргасан гэж үзэхгүй. Гаднын сайт, нэвтрэх/бүртгэлийн
хувийн хэсэг, чимэглэлийн зураг/видео/аудио энэ текстэн сангийн хүрээнд ороогүй.
Хоёр broken link-ийг inventory-д хадгалсан; өөрхаяг/агуулгаар таамгаар нөхөөгүй.

## Файлууд

- `database/website.db`: pages, captures, chunks, assets, crawl_runs, link_inventory.
- `website/snapshots/nmct-20261010T045245Z/`: manifest.json, html/, text/, documents/.
- `website/catalog.json`: URL/гарчиг/татсан огноо/hash-тай локал жагсаалт.
- `website/summary.json`: тухайн цуглуулалтын богино дүн.
- `../runtime/content.db`: хуучин баталгаа/хугацааны хамгаалалттай facts/FAQ сан.

Full snapshot/DB нь локал хадгалагдана; GitHub-д collector, тест, заавар орно.

## Дахин ашиглах команд

Төслийн үндсэн хавтсаас:

```powershell
.\.venv\Scripts\python.exe CORE/website_corpus.py status
.\.venv\Scripts\python.exe CORE/website_corpus.py search "Сургуулийн ажлын цаг" --allow-draft
.\.venv\Scripts\python.exe CORE/website_corpus.py collect
```

Collect нь шинэ snapshot үүсгэнэ; хуучин эхийг дарж бичихгүй.
Ижил snapshot-ийн импорт давхардахгүй; өөрчлөгдсөн текст шинэ version үүсгэнэ.
Хайлтын ердийн горим draft текстийг хаана; `--allow-draft` нь эхийн excerpt харах
хөгжүүлэлтийн горим, сургууль баталсан эсвэл зөв хариулт гэсэн дүгнэлт биш.
BM25 score нь зөв хариултын магадлал биш. Энэ ажил STT training биш.

Элсэлтийн banner «эхэлсэн», main бүртгэл «хаагдсан» гэж зөрнө;
[элсэлтийн эх](https://nmct.edu.mn/elselt)-ийг хугацаа/жилтэй нь хүний нягталгаанд оруулна.
Олдсон төлбөр/огноог шинэ жилд автоматаар хүчинтэй гэж үзэхгүй.
