# Gemini Live-ийн Монгол танилтыг өөрөө турших

**Одоо II · Монгол STT/TTS хэсэг дээр ажиллаж байна.** Таны screenshot дахь
яг **`gemini-3.5-live-translate-preview`** модель чатны сонголтод орсон.
Өмнөх `gemini-3.5-transcribe` нь тусдаа сонголт хэвээр; түүний хуучин
хэмжилт Live Translate-ийн чанарыг батлахгүй.

1. [Үндсэн чатаа нээгээд](http://127.0.0.1:8765/) дахин ачаална.
   «Дуу таних»-аас **Gemini 3.5 Live Translate · Монгол input transcript** сонгоно.
2. «Gemini түлхүүр тохируулах»-ын нууц талбарт AI Studio API түлхүүрээ оруулна.
   Free tier болон өгөгдлийн нөхцөлийг уншиж хоёр чагтыг сонгоод түр холбоно.
3. Нэг асуултаа 5–15 секунд бичнэ, эсвэл өөрийн аудио файлыг сонгоно.
   Дээд хязгаар 30 секунд, 8 MiB. Эхлээд бичлэгээ сонсож шалгана.
4. «Энэ нэг бичлэгийг Google Gemini рүү илгээх» чагтыг сонгоод
   «Дууг текст болгох»-ыг дарна. Бичлэгийн хугацаа болон сүүлийн текстийг
   хүлээх хугацаа орно. Зөвшөөрөлгүйгээр бичлэг автоматаар илгээгдэхгүй.
5. Монгол текстийн нэр/тоо/он, төгсгөлийн үгийг нягтлаад шаардлагатай бол
   засна. Дараа нь ↑ дарж сургуулийн эхтэй RAG асуултаа илгээнэ.

Холболт зөвхөн `serverContent.inputTranscription`-ийг асуултын текст болгоно.
Хэл автоматаар танина; target English, echo off нь screenshot-тай ижил.
Англи орчуулга, орчуулсан дууг чатны асуулт болгохгүй. Үйлчилгээ аудио
гаралт үүсгэж болох тул үүнийг цэвэр текстийн API үнэ гэж тайлбарлахгүй.

Оролтын текст хэсэгчлэн ирдэг. Аудио дууссаныг мэдэгдээд шинэ текст ирэхгүй
хугацааг хүлээнэ: эцэслэх дохиотой бол 3 секунд, дохиогүй бол 8 секунд.
Энэ нь бүх бичлэг бүрэн танигдсаны баталгаа биш. Дохио ирээгүй үед UI
текст дутуу байж болохыг хэлнэ. Хэрэглэгч сонсож нягталсны дараа илгээнэ.
Автомат local LLM засвар cloud танилтад хэрэглэхгүй.

Түлхүүр зөвхөн серверийн санах ойд байна; файл/Git/browser storage-д
хадгалахгүй. Сервер дахин асахад дахин оруулна. Нэг тохиргооны 5 хүртэл
оролдох эрх Live/Transcribe хоёрт хамт үйлчилнэ. 429 дээр зогсоно;
автомат retry, өөр provider эсвэл төлбөртэй горимд шилжүүлэхгүй.

Апп billing/tier-ийг бие даан батлахгүй. AI Studio төсөл Free tier хэвээр
байгааг өөрөө шалгана. Үнэгүй үйлчилгээний өгөгдлийг Google бүтээгдэхүүн
сайжруулахад ашиглаж, хүн хянаж болох нөхцөлтэй.

[үнэ](https://ai.google.dev/gemini-api/docs/pricing),

**10.30-ны нотолгоо:** холбогдох 150 автомат шалгалт PASS; оролтын хэсгүүд,
тасарсан холболт, зөвшөөрөл, model зааг, HTTP/raw lineage, UI handler-ийг
зохиомол transport-оор шалгасан. Локал HTTP-ээр Live сонголт болон session
model-ийг тулгасан. Бодит Google Live танилт 0; шинэ accuracy хэмжээгүй.
Өмнөх аудиог дахин илгээгээгүй. Хадгалсан 12 сонсголын сервер хэвээр.
