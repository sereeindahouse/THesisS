Хэмжилт нь `model.transcribe` болон segment-ийг бүрэн унших хугацаа;
бичлэг хийх, router, хариулт, TTS, дуу тоглуулах хугацаа ороогүй.
Нэг удаагийн batch тул хяналттай давтан latency benchmark биш.
Локал `run_stt_mn_pilot.py`-ийн хэмжсэн хүрээг түүхий13 файлтай тулгасан.
[Нийтэлсэн runtime код](../stt_mn.py), [хадгалсан сонголтын тохиргоо](../config/stt-development.json),
[хувийн текстгүй хэмжилтийн бүртгэл](../docs/experiments/week03-evidence-20261010.json).

Cafet-ийн beam1 нь2.496 секунд/бичлэг болж хурдтай боловч WER46.2%,CER20.5% болсон.
VAD асаахад WER41.9%,CER18.9% болсон. Иймээс beam5/no-VAD/text-only сонголтыг хадгалсан.
186 үгт67 засвар, зайгүй1089 тэмдэгтэд184 засвар: WER нь утгыг зөв ойлгосон accuracy биш.
Нэг хэлэгч, model draft харсан байж болох reference bias, нэр/он/дугаарын алдааны
хязгаарлалтыг хадгална. Энэ харьцуулалтын batch-д шинэ сургалт, inference давтаагүй. Дууны холбоосын
ажиллагааны интеграцийн шалгалт нь тусдаа; энэ 13-ийн quality benchmark-ийг солихгүй.

CPU нь12 logical processor; орчны бүртгэлд AMD64 Family25 Model117 Stepping2,
Windows build26200,Python3.11.9 байсан. RAM-ийн peak/CPU ачаалал, GPU, таблетын
гүйцэтгэл хэмжээгүй. Энэ компьютерт ажилласныг таблет дээр ажиллах баталгаа гэж үзэхгүй.

туршаагүй, шилжүүлээгүй. Үйлчилгээний нөхцөл, SLA, зардлыг баталсан гэж үзэхгүй.

## 3-р долоо хоногийг хаах шалгалт

1. Схем, draft validation, ижил оролтын STT/BM25/E5 харьцуулалт,
   model revision/hash/лиценз, хугацааны хэмжсэн хүрээг хадгална. Техникийн энэ хэсэг бэлэн.
2. Байгаа3 TTS файлыг хүн сонсож нэр/товчлол/тоо/огнооны алдааг бичнэ;
   хоолойг сонгох эсвэл татгалзсан шийдвэрийг бүртгэнэ. Онлайн үйлчилгээний нөхцөлийг
   production хэрэглэхээс өмнө нягтална. Энэ хэсгийг хүний оронд хийсэн гэж тэмдэглэхгүй.
3. C жишээ батлагдаагүй хэвээр бол жижиг LLM туршилт **нөхцөлөөр алгассан** гэж хадгална.
   Бодит батлагдсан C тогтоогдвол тухайн ижил эх/асуултаар л туршина.
4. Сонголтын эцсийн хүний хүлээн авалт ба үлдэх хязгаарлалтыг тусад нь бүртгэнэ.
   Нэг жижиг pilot-ийг бүх хэрэглэгчийн production чанар гэж тайлагнахгүй.

Нэр/он дутууг тодруулах, эхгүй асуултад татгалзах bounded router болон дууны
холбоос хэрэгжсэн. Зэрэгцүүлэн хийх дараагийн ажил: эхийн хувилбар/баталгаа,
PDF/журмын зураг ба client tab-ийн хамрах хүрээ, хүнээр нягтлах dev асуулт/qrel,
бодит төхөөрөмж/орчны шалгалт. 2-р долоо хоногийг дууссан гэж зохиохгүй,
хүний үлдсэн ажлыг бие даасан хэрэгжүүлэлтийн зогсолт болгохгүй.


## Дууны урсгал ба сонсголын нэг дэлгэц — 2026.10.10

Браузерын микрофон/файл → `voice_runtime.py`-ийн локал STT → хэрэглэгч текстээ
засах → `question_router.py` → сервер багц/эхийг дахин шалгах → онлайн Edge TTS
→ хэрэглэгч ▶ дарах холбоос нэмсэн. Cafet revision/hash/beam5/no-VAD/text-only,
CPU/int8 сонголт хэвээр; өөрийн сургалт хийхгүй. STT-ийн анхны гаралт ба зассан
асуултыг ялгана. `model_load_seconds`, `transcription_seconds`, `synthesis_seconds`
зэрэг үе шатны хугацаа нь хүний засах/сонсох хугацаатай нийт latency benchmark биш.

Браузер 20 секундэд бичлэгээ зогсоож, сервер 30 секунд/8 MiB аудионы хязгаар
шалгана. MIME/контейнерийг нягталж mono/16 kHz болгон decode хийнэ. Бэлэн жинг
анх ашиглахад шалгаж ачаалаад дараагийн хүсэлтэд ашиглана. Түр файлыг хувийн
UUID-тай cache-д хадгалж, reset тухайн хуудасны файлуудыг цэвэрлэнэ; эхний WAV,
сонсголын үнэлгээ хэвээр. Эхэлсэн native STT тооцооллыг дундаас нь таслахгүй;
reset-ийн дараах хуучин үр дүнг UI ашиглахгүй. TTS-ийн алдаа текстэн хариултыг
устгахгүй. Хүний өмнөөс микрофоны зөвшөөрөл эсвэл сонсголын баталгаа өгөхгүй.

Микрофоны secure context/хэрэглэгчийн зөвшөөрөл,
[MDN getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia),
дэмждэг бичлэгийн MIME сонгох
[MediaRecorder.isTypeSupported](https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder/isTypeSupported_static),
микрофон track-аа суллах
[MediaStreamTrack.stop](https://developer.mozilla.org/en-US/docs/Web/API/MediaStreamTrack/stop)
гэсэн API нөхцөлд тулгуурласан. Localhost-оос гадна таблетын HTTPS/permission
ажиллагааг тусдаа шалгана. Аудионы decode/resample-ийн эхийг
[faster-whisper 1.2.1 audio.py](https://github.com/SYSTRAN/faster-whisper/blob/v1.2.1/faster_whisper/audio.py)
болон [Edge TTS client](https://github.com/rany2/edge-tts)-тэй холбосон.
Эдгээр нь хэрэгжүүлэлтийн API эх; системийн чанарын баталгаа биш.

`listening_review.py` зургаан STT/гурван хяналттай TTS-ийг demo-оос хүн сонсож
илэрхий батлах form өгнө. Аудионы hash, өөрчлөхөөс өмнөх backup, атомоор файл
солих ба журнал хадгална. Reference баталсны дараа байгаа raw гаралтыг дахин
оноох optional локал алхамтай; шинэ inference/training хийхгүй. q05 excluded
хэвээр; q16-ийн дутуу дугаарыг моделийн таамгаар нөхөхгүй. TTS-ийн 1–5 оноо нь
нэг сонсогчийн subjective feedback, MOS эсвэл эцсийн үйлчилгээний шийдвэр биш.
Энэ хэрэгсэл нэмсэн нь хүн сонсож үнэлсэн гэсэн үг биш.

Текст засах/алдаагаа засварлах, эхийн хязгаарыг харуулах, reset болон тусдаа
хэмжүүрүүд нь [Human–AI/ALCE/RAGAs аргын тэмдэглэл](../papers/06-evaluation-interface-method-notes.mn.md)-ийн
UI ба үнэлгээний үндэслэлтэй нийцнэ. Бүх өгүүллийг бүтнээр уншсан, хэрэглэгчийн
туршилт/MOS хийсэн, эсвэл судалгааны эцсийн хүлээн авалт авсан гэж тайлагнахгүй.
[Demo-г ашиглах заавар](../reports/system/SQLITE-SEARCH.mn.md).
